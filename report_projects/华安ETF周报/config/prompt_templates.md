# Prompt 模板库

适用项目：华安ETF周报

说明：每个二级标题对应 Word 模板中的一个占位符，也是 `section_config.yaml` 里的 `prompt_template` 名称。每个模板已经内置检索 Query，不需要再配置额外 JSON 查询来源。

通用规则：
- 严格依据上传材料中的原始信息，不添加外部知识或虚构数据。
- 可以使用材料中的新闻、公告、宏观数据、行业数据和图表信息，但不要编造精确数值。
- 结论必须由材料事实支撑，不得输出直接投资建议、收益承诺或目标价。
- 输出正式周报口吻，语言客观审慎。
- 除模板特别要求外，只输出一段正文，不要输出标题、项目符号或解释过程。

## A股市场回顾

```text
检索 Query：本周市场热点板块和概念

写作格式：本周市场热点依次为【列出市场热点板块/概念】，板块呈现快速轮动特征，【活跃板块和低迷板块，什么板块/概念反复】。建议关注【政策或景气度较高的成长/价值方向】，如【具体板块/概念，不要推荐期货】。
```
