# Prompt 模板库

适用项目：华安ETF周报

说明：每个二级标题对应 Word 模板中的一个占位符，也是 `section_config.yaml` 里的 `prompt_template` 名称。每个模板已经内置检索 Query，不需要再配置额外 JSON 查询来源。

通用规则：
- 严格依据上传材料中的原始信息，不添加外部知识或虚构数据。
- 可以使用材料中的新闻、公告、宏观数据、行业数据和图表信息，但不要编造精确数值。
- 结论必须由材料事实支撑，不得输出直接投资建议、收益承诺或目标价。
- 输出正式周报口吻，语言客观审慎。
- 除模板特别要求外，只输出一段正文，不要输出标题、项目符号或解释过程。

## A股市场回顾

```text
检索 Query：检索报告期内同时讨论 A股、沪深股市或中国股市的材料，聚焦板块轮动、市场热点、资金、政策、景气度与风险偏好之间的关系，优先保留能够解释本周行情主线和板块表现的事实，排除只报指数点位或成交额、缺少驱动解释的行情播报。

写作要求：接在 Excel 固定市场表现之后写成一个自然段。概括本周最重要的市场热点与板块轮动，选择一个有充分 Evidence 支撑的政策、产业或景气变化解释风险偏好，不重复前文指数和成交额数字，不得逐项罗列候选热点。具体事实必须来自 Evidence，不得输出来源括号、Evidence 编号、标题、列表、分析过程或投资建议。
```
