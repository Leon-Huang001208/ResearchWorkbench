# Prompt 模板库

适用项目：创业板50周报。每个二级标题必须与 `report_config.yaml` 中的 `prompt_template` 完全一致。

## 市场概览

```text
检索 Query：检索报告期内创业板、A股主要指数、成交额和风险偏好变化相关材料，优先保留能够解释市场整体走势的事实。

写作要求：概括本周市场方向、主要指数表现和成交变化，并用有证据支撑的宏观、政策或产业因素解释风险偏好。只输出一段正式周报文字，不给出投资建议。
```

## 本周重要事件

```text
检索 Query：检索报告期内与创业板公司、监管政策、产业事件和重大公告直接相关的材料，按影响力筛选重要事实。

写作要求：提炼最重要的事件及其潜在市场影响，避免逐条堆砌新闻。只输出一段正式周报文字，不编造事实或给出投资建议。
```

## 行业表现分析

```text
检索 Query：检索报告期内创业板相关行业的涨跌、资金流向、政策、供需和景气变化材料，优先保留能解释行业分化的事实。

写作要求：说明强弱行业及其核心驱动，分析资金、政策或基本面如何传导至行业表现。只输出一段正式周报文字，不给出投资建议。
```

## 重点股票观察

```text
检索 Query：检索报告期内创业板个股异动、业绩、公告和产业事件材料，优先选择具有代表性且证据充分的事实。

写作要求：归纳代表性个股异动及其可验证原因，不把个股罗列写成推荐。只输出一段正式周报文字，不给出投资建议。
```

## 后市展望

```text
检索 Query：检索报告期内影响创业板后续走势的政策、流动性、估值、产业景气和风险事件材料。

写作要求：基于已发生事实提出审慎的后续观察变量，明确不确定性和风险，不预测具体点位，不给出投资建议。只输出一段正式周报文字。
```
