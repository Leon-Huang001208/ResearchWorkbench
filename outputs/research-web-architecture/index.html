Research Workbench Research Web / 当前架构

从研究问题，到真实文件交付

以当前源码为依据，区分产品职责、DSH 执行和文件检查。旧量化与 merged-platform 图文不属于此运行链。

以下八图对应当前研究链路、能力管理与文档门禁的实际源码。图形检查不等于模型内容准确性证明；真实会话、文件及验证边界另记录在架构 Markdown 与验收报告中。
01 / DEPLOYMENT

部署与安全边界

浏览器、FastAPI、专属 DSH、模型接口与会话内脚本隔离。

 02 / MODULES

前后端模块依赖

产品壳、输入框、能力编辑、领域服务与原生执行的源码分工。

 03 / SEQUENCE

研究请求、审批与恢复

受理与完成分离；双 WebSocket、SSE、停止及历史恢复。

 04 / DATA FLOW

数据快照到共享分析

受控公开数据、同一数据集、子 Agent、资料和实际产物。

 05 / CAPABILITIES

能力包、发布与原生调用

草稿检查、不可变版本、原生目录和会话只读资源的边界。

 06 / RUN STATE

研究执行状态

原生状态的产品投影，连接中断不伪报完成；图示为主要分支。

 07 / DELIVERY

独立文件交付状态

只认可本次输出；文件有效性、缺失与损坏单独检查。

 08 / ITERATION

迭代与图文同步检查

源码映射、说明更新、图源与回执、人工核对及本地／CI 共用门禁。
