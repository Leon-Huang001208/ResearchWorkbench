# 验收·样本统计报告（ui-sample-report-verified）

用于样本统计与文件交付验收。输入仅为用户在会话中给出的**数值列表与问题**；输出是在本会话 `outputs` 生成的**独立 HTML 统计报告**。除 `research_run_script` 外不使用其它工具：不联网、不安装依赖、不读取会话外文件、不自动发布。

## 1. 检查并澄清输入
- 索取并确认两项内容：用户提供的数值样本（允许若干整数/浮点）与随附的问题文本。
- **缺失、字段非数字、或值为空**：不要用估算值或占位符填补，而要**明确向用户提出澄清请求**，等待其补齐后再继续。
- 允许记录被剔除的非数字项，但不得把剔除当作可用统计结果；若全部无效，在澄清前不谈输出。

## 2. 用 Python 计算统计量（仅 research_run_script）
- 对*已确认有效*的样本计算：
  - **样本数 n** = 有效数值个数；
  - **总和 sum** = 有效数值之和；
  - **平均值 mean** = sum / n。
- 若 n 为 0：**不得以 NaN 冒充有效输出**——直接返回并向用户澄清输入，注明尚未生成可复算报告及原因。
- 脚本注释写明口径（mean=sum/n）以便复核；脚本本身不做任何联网或文件外的访问。

## 3. 生成真实、独立的 HTML 报告
- 产出 UTF-8、可单独打开的 HTML 文件（`<meta charset="utf-8">`）：
  - 报告标题与用户问题；
  - 每条输入值的序号与原始值（记录表）；
  - 汇总区：样本数、总和、平均值；
  - 注明文件路径、统计口径和"未联网"的依据。
- 报告是真实生成的文件，不是聊天文本的代称。

## 4. 读回验证
- 重新以只读方式打开刚生成的 HTML，逐项核对表内每个数值与报告汇总（n/sum/mean）是否与第 2 步的内存计算结果一致。
- 任一不一致须在交付文件或答复中如实注明，不得删除差异。

## 5. 交付
- 默认交付 `html`；在最终答复列出实际文件路径、所用技能与未完成事项。
- 用户另有要求才考虑其它格式；不以 Word/Excel/聊天正文替代 HTML 验收交付物。

## 约束
- 工具：仅 `research_run_script`；不 `web_search`、不取公共数据、不访问会话外宿主文件。
- 依赖：不执行 `pip install`、不引入未预装第三方包；确需则如实注明缺失而非假装可用，故 capability 中 dependencies 保持为空（stdlib 不写入）。
- 候选包：根目录仅 `SKILL.md` 与 `capability.json`；`workflow-draft-reference.json` 为验收草稿参考，非启用 Skill。
- 发布权在用户：仅产出草稿供审查，不自动发布、不改权限、不加字段。
