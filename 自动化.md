# 优先级 1：爬虫 → Ingestion 打通

## 现状问题

你现在是：

```text
CLS / CNStock / AKShare crawler
    ↓
独立 CLI / 独立输出
```

但理想是：

```text
Crawler
    ↓
DocumentEnvelope / RawItem
    ↓
IngestionQueue
    ↓
KnowledgePipeline
```

## 应该做什么

新增一个统一入口：

```text
core/services/crawler_ingestion_bridge.py
```

作用是把所有爬虫输出统一变成 `DocumentEnvelope` 或 `IngestionQueueItem`。

示意代码：

```python
class CrawlerIngestionBridge:
    def __init__(self, queue_service, knowledge_pipeline):
        self.queue_service = queue_service
        self.knowledge_pipeline = knowledge_pipeline

    def submit_crawled_item(self, source_type, item):
        envelope = self._to_document_envelope(source_type, item)

        return self.queue_service.enqueue({
            "source_type": source_type,
            "source_id": envelope.doc_id,
            "title": envelope.title,
            "raw_content": envelope.raw_text,
            "url": envelope.metadata.get("url"),
            "priority": self._infer_priority(source_type, envelope),
        })

    def _to_document_envelope(self, source_type, item):
        return DocumentEnvelope(
            doc_id=item.get("id") or self._hash_item(item),
            source_type=source_type,
            source_name=item.get("source_name", source_type),
            title=item.get("title", ""),
            raw_text=item.get("content", ""),
            canonical_text=item.get("content", ""),
            published_at=item.get("published_at"),
            metadata={
                "url": item.get("url"),
                "crawler": source_type,
            },
        )
```

然后改所有 crawler：

```text
crawler.fetch()
    ↓
bridge.submit_crawled_item()
```

不要让 crawler 直接写业务表。crawler 只负责抓，KnowledgePipeline 负责理解。

## 修复 AKShare 适配器断裂

你审计里提到 `DataSourceRouter` 的 AKShare 适配器引用断裂。这个要单独补一个适配层：

```text

```

统一暴露：

```python
class AkShareAdapter:
    def fetch_stock_master(self): ...

    def fetch_news(self, limit=100): ...
    def health_check(self): ...
```

# 优先级 2：队列 Worker 自动处理

现在要避免这种模式：

```text
用户手动点 API → 处理一批
```

改成：

```text
后台 worker 常驻 → 自动消费 queue → 自动跑 KnowledgePipeline
```

新增：

```text
workers/knowledge_worker.py
```

逻辑：

```python
import asyncio
from data_layer.repositories.base import SessionLocal
from core.services.knowledge_pipeline import KnowledgePipeline
from data_layer.repositories.ingestion_repository import IngestionQueueRepository

async def main():
    while True:
        db = SessionLocal()
        try:
            queue_repo = IngestionQueueRepository(db)
            pipeline = KnowledgePipeline(db=db)

            items = queue_repo.dequeue(limit=10)

            if not items:
                await asyncio.sleep(3)
                continue

            for item in items:
                try:
                    result = pipeline.process_raw_item(item)
                    queue_repo.mark_completed(item.item_id, result=result)
                except Exception as e:
                    queue_repo.mark_failed(item.item_id, error=str(e))

        finally:
            db.close()

if __name__ == "__main__":
    asyncio.run(main())
```

如果 `KnowledgePipeline` 现在已经有框架，就不要绕过它。所有数据都应该经过它。

# 优先级 6：端到端 Orchestrator

现在 Orchestrator 是线性执行。你需要一个真正的状态机。

新增：

```text
core/services/end_to_end_orchestrator.py
```

状态：

```text
RAW_INGESTED
DOCUMENT_PARSED
ASSERTIONS_EXTRACTED
EVENTS_EXTRACTED
EVENTS_VALIDATED
PROPAGATION_ANALYZED
REASONING_COMPLETED
SIGNAL_GENERATED
BACKTEST_COMPLETED
OUTCOME_RECORDED
PUBLISHED_TO_FRONTEND
FAILED
```

伪代码：

```python
class EndToEndOrchestrator:
    def run_item(self, item_id):
        item = self.queue_repo.get(item_id)

        doc = self.knowledge_pipeline.process(item)
        self.event_bus.publish("document_parsed", doc)

        assertions, events = self.extract_knowledge(doc)
        self.event_bus.publish("events_extracted", events)

        for event in events:
            propagation = self.propagation_analyzer.analyze(event)
            self.event_bus.publish("propagation_completed", propagation)

            reasoning = self.reasoning_engine.reason(event, propagation)
            self.blackboard_repo.save(reasoning)

            signal = self.signal_generator.generate(event, propagation, reasoning)
            self.signal_repo.save(signal)
            self.event_bus.publish("signal_generated", signal)

            backtest = self.backtest_service.run(signal)
            self.backtest_repo.save(backtest)
            self.event_bus.publish("backtest_completed", backtest)
```

这会让系统从“几个模块能跑”变成“端到端自动跑”。
