# 文档更新规范

## 概述

进行任何功能变更时，必须同步更新相关文档，确保文档与代码保持一致。

---

## 文档清单

| 文档 | 位置 | 更新场景 |
|------|------|----------|
| README | `README.md` | 新增核心功能、变更安装方式、更新进度标记 |
| 快速开始 | `docs/QUICKSTART.md` | 新增安装步骤、变更配置方式、新增快速入门示例 |
| CLI 指南 | `docs/CLI_GUIDE.md` | 新增 CLI 命令、变更命令参数、新增使用示例 |
| 架构设计 | `docs/ARCHITECTURE.md` | 变更架构、新增模块、修改核心设计 |
| 其他文档 | `docs/*.md` | 根据文档内容确定 |

---

## 需要更新文档的场景

### 新增功能时

- [ ] 更新 README.md 功能列表
- [ ] 添加或更新使用示例
- [ ] 更新相关的指南文档
- [ ] 如有新 CLI 命令，更新 CLI_GUIDE.md

### 变更 CLI 命令时

- [ ] 更新 CLI_GUIDE.md 中的命令说明
- [ ] 更新参数列表和说明
- [ ] 添加新的使用示例
- [ ] 更新命令速查表

### 变更配置时

- [ ] 更新 .env.example
- [ ] 更新 QUICKSTART.md 中的配置说明
- [ ] 更新相关文档中的配置引用

### 变更架构时

- [ ] 更新 ARCHITECTURE.md（如存在）
- [ ] 更新目录结构说明
- [ ] 更新模块关系说明
