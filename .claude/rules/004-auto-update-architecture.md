# 强制规则：自动更新所有相关文档

## 三个文档的定位

| 文档 | 定位 | 受众 | 核心内容 |
|------|------|------|----------|
| **ARCHITECTURE.md** | 系统设计文档 | 架构师、核心开发者 | 系统架构、设计决策、技术选型、模块关系 |
| **USER_GUIDE.md** | 用户使用手册 | 最终用户、操作人员 | 如何使用工具、命令说明、工作流程 |
| **FRAMEWORK-GUIDE.md** | 框架开发指南 | 框架开发者、扩展者 | 如何使用/扩展框架、创建新Wiki实例 |

## 适用范围

当你进行以下任何操作时，必须同步更新相关文档：

### 需要更新 docs/ARCHITECTURE.md 的情况：

1. **新增/删除/重命名** 项目核心文件或目录
2. **修改** 配置文件结构（config.yaml、.claude/settings.json）
3. **新增/修改** 自动化工具或插件
4. **新增/修改** 规则文件（.claude/rules/）
5. **新增/修改** 项目级指令（CLAUDE.md）
6. **新增/修改** 核心功能模块或系统
7. **任何会影响项目架构理解** 的改动

### 需要更新 docs/USER_GUIDE.md 的情况：

1. **新增** 工具脚本或 CLI 命令
2. **修改** 现有工具的使用方式或参数
3. **新增** 功能模块或工作流程
4. **修改** 配置文件格式或位置
5. **任何会影响用户使用方式** 的改动

### 需要更新 docs/FRAMEWORK-GUIDE.md 的情况：

1. **修改** 框架核心架构
2. **新增** 框架级功能或 API
3. **修改** 框架配置或扩展方式

## 检查清单

在完成任何上述改动后，必须确认：

### docs/ARCHITECTURE.md 检查清单（如适用）：

- [ ] 已读取当前的 `docs/ARCHITECTURE.md`
- [ ] 已更新"目录结构"部分
- [ ] 已更新"关键文件说明"表格
- [ ] 已更新"分阶段实施计划"
- [ ] 已更新"新增特性说明"章节

### docs/USER_GUIDE.md 检查清单（如适用）：

- [ ] 已读取当前的 `docs/USER_GUIDE.md`
- [ ] 已在"核心工具"章节新增/更新工具说明
- [ ] 已在"功能模块"章节新增/更新功能说明
- [ ] 已在"配置说明"章节新增/更新配置说明
- [ ] 已在"常见工作流程"章节新增/更新流程说明
- [ ] 已在"命令速查表"章节新增/更新命令
- [ ] 已在"版本历史"章节记录本次变更

### docs/FRAMEWORK-GUIDE.md 检查清单（如适用）：

- [ ] 已读取当前的 `docs/FRAMEWORK-GUIDE.md`
- [ ] 已在"快速开始"章节新增/更新内容
- [ ] 已在"配置说明"章节新增/更新配置说明
- [ ] 已在"工作流"章节新增/更新流程说明

## 例外情况

以下情况不需要更新文档：

- 修改 Wiki 内容（wiki/ 目录下的文件）
- 修改原始数据源（raw/ 目录下的文件）
- 修改临时文件或缓存文件
- 纯代码 bug 修复，不涉及功能/架构/使用方式变更
- 纯格式调整，不影响功能理解
