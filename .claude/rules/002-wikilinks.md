# WikiLinks 交叉引用规范

## 要求

在 Wiki 页面内容中，**必须大量使用 WikiLinks**（`[[页面名称]]` 格式）来连接相关概念。

## 何时使用 WikiLinks

- 提到任何个股时 → `[[贵州茅台]]`
- 提到任何指数时 → `[[沪深300]]`
- 提到任何概念时 → `[[AI人工智能]]`
- 提到任何机构时 → `[[国金证券]]`
- 提到任何来源时 → `[[2025-11-24-国金证券-数看期货]]`

## WikiLinks 格式规范

- 使用 `[[页面名称]]` 格式
- 页面名称必须与实际文件名完全匹配（不含 `.md` 扩展名）
- 如果页面在子目录中，仍只需使用文件名：`[[贵州茅台]]`（不需要 `[[entities/个股/贵州茅台]]`）

## 检查清单

在写入 Wiki 页面内容时：

- [ ] 所有提到的实体都已添加 WikiLinks
- [ ] WikiLinks 指向正确的页面名称
- [ ] 避免重复链接同一页面太近（同一页面内同一概念可只在首次提及时链接）
