# Component Rules

# Philosophy

Components should feel:

- reusable
- operational
- dense
- modular

NOT decorative.

---

# Cards

## Structure

Header
Metadata
Primary Data
Secondary Data
Actions

---

## Hover

Subtle brighten only.

No floating cards.

---

# Tables

## Rules

- compact rows
- sticky header
- mono numbers
- sortable
- filterable

---

## Row Height

Default:
32px

Compact:
28px

---

## Numeric Alignment

All numeric values:
right aligned

---

# Sidebar

## Width

Expanded:
240px

Collapsed:
72px

---

## Active State

Requirements:
- darker background
- accent border
- subtle glow

---

# Search Bar

Always visible.

Should resemble command palette.

---

# Buttons

## Variants

- Primary
- Secondary
- Ghost
- Danger

---

# Modals

Avoid large modals.

Prefer:
- side panels
- expandable sections

---

# Empty States

Should still feel operational.

GOOD:
No signals detected today.

BAD:
Nothing here yet :)

---

# AI Insight Panels

Structure:
- signal
- confidence
- evidence
- related assets
- suggested action

NOT chatbot conversations.
