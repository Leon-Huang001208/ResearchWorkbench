# Preferred Prompt Style

Describe:
- workflow
- constraints
- hierarchy
- density

NOT vague aesthetics.

---

# GOOD Prompt

Build a compact signal feed panel for institutional equity research.

Requirements:
- dark terminal aesthetic
- dense layout
- mono numeric data
- subtle hover
- amber accent only
- no gradients

---

# BAD Prompt

Make it futuristic and beautiful.

---

# Good Modifications

- reduce row height
- improve typography hierarchy
- increase scan efficiency

# Bad Modifications

- make it more premium
- make it prettier
- make it more modern
