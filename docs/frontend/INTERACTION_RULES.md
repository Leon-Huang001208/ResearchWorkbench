# Interaction Rules

# Hover

Cards:
slight brighten only

Rows:
subtle background highlight

Buttons:
slight accent shift

---

# Active States

Must always be clearly visible.

Use:
- darker background
- accent border
- subtle glow

---

# Loading

Prefer:
- skeleton loading

Avoid:
- spinner-only loading

---

# Animations

Allowed:
- fade
- subtle pulse
- opacity transition

Forbidden:
- bounce
- spring motion
- parallax
- floating effects

---

# Tables

Hover:
rgba(255,255,255,0.03)

Selected:
accent border

---

# Search

Search must feel:
- instant
- command-palette-like
- keyboard-first
