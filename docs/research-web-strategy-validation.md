# 策略验证

入口为「策略模拟」→「策略验证」。导入以数据规格和 SHA-256 回执封存的日线 ZIP，选择数据集、规则和结果期限，按「运行验证」创建一次研究回放。页面可查看历史运行和按规则分页的每笔触发结果。

## 研究规则

| 规则 | 触发时点与口径 |
| --- | --- |
| 放量滞涨 | 当日收盘在前高下方给定范围内，涨幅为 0% 至不足 1%，原始成交股数达到此前五日均量的配置倍数。前高窗口排除信号日 |
| 5 日均线破位 | 前一日收盘在该日 SMA5 上或线上，当日收盘低于该日 SMA5 |
| 10 日均线破位 | 前一日收盘在该日 SMA10 上或线上，当日收盘低于该日 SMA10 |
| 20 日均线破位 | 前一日收盘在该日 SMA20 上或线上，当日收盘低于该日 SMA20 |

默认前高计算为此前 20 个交易日，距离为 2%，量比为 1.30。均线匹配分别限制前一日和信号日距线为 3% 和 2.5%。观察期限可选第 1、5、10 个交易日。各均线包含该日收盘价，均线和收益用参考前收连接可比价格，成交量用原始股数。日行情按交易日历对齐，样本限有有效成交的普通沪深主板股，保留原流动性与公司行动窗口条件。

触发收益从下一交易日开盘算到期限收盘。相似对照为同交易日、同交易所、符合对应接近条件且未触发的最近样本，匹配只用信号日及此前特征。结果缺失的配对不因事后数据换人。逐笔记录附匹配对照股票、对照收益和距离。

下跌率的分母是有持有收益的触发事件。卖出胜率的分母是两端都可假设成交的事件，赢为次日开盘卖出的净终值严格高于持有至期限收盘卖出的净终值，平局计入分母。两种情形各扣一次设定的退出费用，现金收益取零。停牌、ST 和跌停等状态按引擎的可成交近似处理。均值和区间来自完整交易日上的分块抽样。四条规则各自统计，同股同日可能触发多条。

## 数据与权限

当前输入版本为本任务的冻结 BaoStock 沪深主板研究样本。ZIP 可以包含前次命令行研究包的代码和结果，入口只读取行情、日历、样本名录、数据规格及相应哈希回执。包中代码和历史结果不参与计算。账号存储以服务解析的账号数据根为准。

上传和运行需要明确用户动作。服务限制 ZIP、解开字节、成员数、配置、并发及存储规模，运行使用冻结输入和本次配置。重复提交沿同一幂等键读取同一运行，键和配置冲突拒绝。文件中的自报哈希只说明内容一致性，不能确认历史当时可得版本。结果为研究回放，默认卖出条件、正式交易和自动化没有此入口。

在 macOS Native 和 Docker 的现有 Web 依赖里使用已锁定 pandas、NumPy 和 Python 标准库。计算在 Host 完成，依赖当前实例的 Web 鉴权和维护准入。

## API

请求前缀为 `/api/research/strategy-validation`。

- `GET /` 列出当前账号的数据集和运行。
- `POST /datasets` 上传原始 ZIP 内容，要求 `X-Research-User-Action: ?1`。
- `POST /runs` 冻结配置并执行，需要同一动作头和 `Idempotency-Key`。
- `GET /runs/{id}` 读取规则摘要和覆盖。
- `GET /runs/{id}/events?rule=...&offset=0&limit=50` 读取逐笔触发。
