# Chief 每日任务登记核对清单

## 1. 核对任务登记

- [ ] 汇总 Chief 当日收到的任务，逐项核对是否已登记。
- [ ] 检查每条登记是否包含任务名称、需求来源、负责人、登记日期和当前状态。
- [ ] 确认任务描述写明预期结果和验收条件；信息缺失时标记为待补充。
- [ ] 排查重复登记；相同需求保留一条主记录，并注明关联记录。

## 2. 核对候选确认

- [ ] 检查候选任务是否有明确的确认结果：待确认、已确认或不采纳。
- [ ] 对已确认的候选任务，记录确认人、确认时间及确认依据的链接。
- [ ] 核对确认后的任务范围、优先级和负责人是否与登记内容一致。
- [ ] 对尚未确认或存在分歧的候选任务，记录待解决问题及跟进人，避免误标为已确认。

## 3. 核对任务 ID

- [ ] 确认每个已确认任务都有唯一的任务 ID。
- [ ] 检查任务 ID 是否与任务登记系统中的原始记录一致，避免遗漏、重复或录入错误。
- [ ] 核对候选确认记录、执行记录和关联 PR 中引用的任务 ID 是否一致。
- [ ] 如发现重复 ID 或错误关联，先核实原始记录，再更正引用并注明更正原因。

## 4. 核对 PR 链接

- [ ] 对已提交代码或文档变更的任务，检查是否登记完整、可访问的 PR 链接。
- [ ] 打开 PR，核对所属仓库、标题、变更内容及关联任务 ID，确认链接指向正确任务。
- [ ] 检查 PR 状态，并同步记录为待评审、修改中、已合并或已关闭。
- [ ] 一个任务对应多个 PR 时，逐一登记链接并注明各自用途；一个 PR 关联多个任务时，明确列出对应任务 ID。
- [ ] 尚未创建 PR 的任务注明“未创建”；无需 PR 的任务注明“不适用”及原因。

## 5. 完成每日核对

- [ ] 确保每个已确认任务都能从登记记录追溯到确认依据、任务 ID 和适用的 PR 链接。
- [ ] 汇总缺失信息、错误关联及状态不一致的问题，为每项指定跟进人。
- [ ] 记录本次核对日期、核对人和未解决事项；下次核对时优先复查。
