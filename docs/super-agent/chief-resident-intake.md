# Chief 白名单任务接入核对

本文用于在 RWB 中核对 Chief 白名单任务是否已登记、是否正在等待发布确认，以及当前关联的 PR。所有状态均以可核验记录为准；缺少证据时标记为“待核实”。

## 核对任务已登记

1. 在 RWB 的任务登记记录中查找对应的 Chief 白名单任务。
2. 核对任务名称或编号、负责人、白名单范围与任务描述是否一致。
3. 记录登记条目的链接或编号，确认该记录可以访问且能够唯一对应本次任务。
4. 只有找到匹配的登记记录后，才将登记状态标记为“已登记”；未找到或信息不一致时，标记为“待核实”并说明缺项。

## 核对等待发布确认

1. 查看任务记录及关联 PR 中最新的发布说明或确认记录。
2. 确认是否已有明确的发布确认请求，并核对待确认的变更范围、确认负责人及请求时间。
3. 若已提出确认请求，但尚无对应范围的明确确认结论，将状态标记为“等待发布确认”，并附上请求记录链接。
4. 若已有确认结论，记录结论及证据链接；不得继续沿用“等待发布确认”。没有确认请求记录时，标记为“待核实”。

## 核对当前 PR

1. 从任务登记记录中打开关联 PR，核对其仓库、标题、变更目的及目标分支是否对应本次任务。
2. 查看 PR 的最新状态，记录其为草稿、开放、已合并或已关闭，并核对评审与检查结果。
3. 若关联了多个 PR，依据任务记录中的最新明确指向识别当前 PR，同时记录其他 PR 的关系；无法确定时标记为“待核实”。
4. PR 已合并不等于已发布，检查通过也不等于发布已获确认；发布确认状态应单独依据确认记录核对。

## 核对结果记录

核对完成后，填写以下信息。本文未提供实际任务或 PR 证据，初始状态均为“待核实”。

| 核对项 | 结果 | 证据或说明 |
| --- | --- | --- |
| Chief 白名单任务名称／编号 | 待核实 | 填写任务标识 |
| 任务登记状态 | 待核实 | 填写登记记录链接或编号 |
| 负责人及白名单范围 | 待核实 | 与登记记录逐项核对 |
| 发布确认状态 | 待核实 | 填写确认请求或确认结论链接 |
| 发布确认负责人 | 待核实 | 以确认请求记录为准 |
| 当前 PR | 待核实 | 填写 PR 链接及编号 |
| PR 状态、评审与检查结果 | 待核实 | 以 PR 最新记录为准 |
| 核对人及核对时间 | 待填写 | 记录实际核对人、日期和时区 |

发现登记信息、发布确认记录与当前 PR 不一致时，应记录差异并向对应负责人核实，取得明确证据后再更新结果。
