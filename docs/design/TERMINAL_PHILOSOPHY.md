# Terminal Philosophy

Research Workbench is not a website.

It is a financial operating system.

---

# Emotional Tone

The UI should feel:

- calm
- focused
- analytical
- operational

NOT:
- playful
- flashy
- social-media-like

---

# User Mindset

Users are power users.

Dense interfaces are acceptable.

---

# AI Philosophy

AI is an analyst.

NOT a chatbot.

AI outputs should feel:
- evidence-based
- structured
- confidence-weighted
- actionable

---

# Core Principle

Every UI element must improve research velocity.
