# Research Workbench DESIGN.md

## Product Identity

Research Workbench is an AI-native financial research operating system.

The interface should feel like:

- Bloomberg Terminal
- TradingView Desktop
- Linear
- Institutional quant platform

NOT like:

- startup landing page
- crypto casino UI
- dribbble concept art
- glassmorphism dashboard

---

# Core Philosophy

## Information Density First

The system prioritizes:

- scan efficiency
- workflow speed
- operational clarity
- research throughput

Whitespace is controlled and intentional.

---

## Terminal Aesthetic

The UI should feel:

- operational
- analytical
- real-time
- professional

NOT playful or decorative.

---

## Minimal Visual Noise

Avoid:
- giant gradients
- glossy UI
- huge shadows
- floating elements
- rainbow colors

---

# Layout

## Density

High-density layout preferred.

Compact but readable.

---

## Radius

Cards:
16px

Buttons:
10px

Inputs:
10px

---

# Motion

Use subtle motion only.

Good:
- hover brighten
- fade transition
- subtle pulse

Bad:
- bounce
- floating motion
- elastic animation

---

# Charts

Charts should resemble institutional trading systems.

Preferred:
- dark backgrounds
- muted grids
- minimal labels
- high contrast data

Avoid:
- rainbow palettes
- glossy charts
- decorative effects

---

# Final Principle

Every UI element must answer:

Does this improve research velocity?
