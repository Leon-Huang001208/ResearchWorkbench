# 多用户常驻部署与旧实例保留

用户明确授权部署到Mac mini并保留现有会话和模型配置，实际验证多用户登录/隔离。

1. 将已归属的旧resident绑定唯一primary管理员，不移动数据、不读取或复制旧模型密钥、不重启原Web/DSH。新账号继续独立运行，primary占一个容量槽。
2. 增加显式多用户LaunchAgent入口和只读健康检查；固定已交付源码SHA、原生产解释器及Node/DSH。启动/停止只控制新网关及其创建的新用户进程。
3. 新网关原子journal在Tailscale切换之前；旧supervisor/admission/lifecycle锁内检查空闲及数据/模型摘要，原实例始终运行。失败恢复原443→8088代理，不覆盖任何业务文件。旧自动升级白名单不扩大。
4. 首管密码只进入本机Keychain；新增账号库和配置为私有文件。primary账号不能被普通账号操作或被网关停止。常驻退出正常回收新用户实例，重启登录的新boot仅在旧owner含不同kernel boot ID时退休残留元数据；同boot未知进程保持blocked。
5. 测试覆盖身份绑定/容量/primary保护、journal/回滚、原数据快照、重启残留。交付后从精确master部署，真实HTTPS双浏览器账号验证登录、旧会话、模型存在状态和会话/文件越权拒绝；不发送模型生成请求。

验收分开记录源码/CI、常驻安装、真实登录/隔离、数据与模型保留、实际重启；真实机器重启和付费生成不冒充通过。最终证据在私有resident目录，生产账号、会话内容和秘密不进入Git/CI。
