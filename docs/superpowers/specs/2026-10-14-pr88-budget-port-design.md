# PR88 持久验收预算适配

依据已确认的 PR 清理方案与继续授权，从 master `38c180953` 提取 #88 唯一未覆盖的
有界文本验收机制。保留当前 AES/Fernet/Keychain，不迁回旧明文 model_file_store，不改
DSH pin、依赖、部署、用户设置页或日常实例。当前宿主 macOS，其他平台证据独立交接。

控制和账本仍绑定 32 位实例身份，使用已验证的私有目录、FD、永久锁、控制摘要、原子替换
与读回。最多 3 张不可退款票，每张输出最多 512 tokens，累计最多 1536；输入和费用按
旧策略预留。旧费率只是历史锁定字段，政策到期仍为 2026-10-10，当前真实时钟必须拒绝。
不更新报价、不续期、不初始化真实账本或复制旧 Key；未来窗口必须另有明确授权和政策复核。

默认运行不发现或创建账本。仅显式 docker-text 控制可在已认证的受管 AES 身份下加载已有
控制；本轮拒绝无法认证稳定身份的 Fernet/Native text-profile，普通 Fernet/Native 不变。
身份验证不宣称认证 dev/stage/prod 角色；后续真验收必须选择独立候选实例。

guard 在每次模型调用前持久扣票，失败/取消不退票；禁止工具、附件和重试，输出上限与
已授权控制一致，只使用固定 DSH 的官方 Messages endpoint。私有 Python RPC 继续
隔离解释器、清洁环境、有界 stdin/stdout、固定错误码，不跨管道传 prompt 或凭据。
截止先标记过期，再通过固定 SDK 公开 Agent.cancel 中止已绑定的原请求 signal，并请求
iterator 清理。必须核对原生 loop marker、会话身份与当前 owner signal，未知或陈旧请求
预拒绝，旧 timer 不能取消下一轮。供应商是否停止远端计算不能由本地 abort 认证；已预留
额度不退款，迟到数据不能重新打开授权窗口。

验收先取得 RED 再验证账本并发、读不创建、拒绝重置、篡改/alias/权限/未知提交、过期，
以及 launcher 绑定、默认不启用、guard 私有 RPC、扣票、上限和取消/到期。注入历史时钟只
用于临时测试目录；不作为当前有效预算或真实模型证据。最终 SHA 需本地回归、必需治理与
自动 macOS 干净安装 CI。Windows/Linux 原生及产品 CI、真实推理保持 NOT_RUN。
