# 报告配置工作台降噪设计

## 目标

保留现有“左侧配置导航 + 右侧当前段落编辑”的工作台结构，让用户在新上传或维护报告模板时，先看见当前要完成的配置，而不是同时面对检查明细、关键词、变量映射和高级检索参数。

## 信息层级

### 左侧导航

- 保留共用 Prompt 约束、证据来源与时间、检索策略、证据重排四项入口。
- 生成检查默认只显示总状态、占位符映射完成度和可生成段落数。
- 完整检查明细只在用户点击“查看检查详情”后展开。

### 当前段落

- 顶部保留段落选择器、类型标签、保存按钮和完成状态。
- 段落主体默认显示：基础参数摘要、当前需要处理的配置项（例如语义 Query）和下一步操作。
- 关键词、固定开头模板、Excel 变量来源、写作结构均变为可展开摘要；摘要包含数量、来源或引用数，避免展开大量标签、长文案和表格。
- 当配置不完整时，优先展开唯一阻塞项，并在顶部明确说明缺少什么；配置完整时，默认只展开基础参数与 Query 摘要。

### 高级配置

- 右上“高级配置”承载低频全局参数：检索候选数和权重、来源类型、重排模型、报告日期及证据时间范围、全局 Prompt 约束。
- 这些参数继续可编辑，但不在段落配置的默认视图中占据空间。

## 交互规则

1. 用户通过左侧入口切换全局配置，通过顶部选择器切换段落。
2. 段落卡片的可展开区保持原有编辑入口；展开后才渲染完整关键词、模板内容和变量表。
3. “保存并配置下一段”保存成功后选择下一个未完成段落；没有未完成段落时保持当前段落并提示已完成。
4. 检查状态与实际验证结果保持一致；摘要不隐藏任何阻塞问题，只隐藏已通过的逐项细节。
5. 没有 JavaScript 时仍保留基础 HTML 内容和原有详情入口。

## 视觉规则

- 不改变深色主题、左右栏比例和主要控件位置。
- 使用现有紫色作为交互和需要处理状态的强调色，红色仅用于真实缺失或阻塞项。
- 避免同屏渲染超过一组标签云、一个长文本预览或一张变量表。
- 摘要卡片采用统一高度和单行元信息，强调“是什么、完成度、下一步”。

## 验收标准

- 配置页初始视图不展示完整关键词标签云、Excel 变量表或生成检查明细。
- 用户仍可从当前段落打开并编辑 Query、关键词、固定模板、变量来源和写作结构。
- 存在缺失配置时，顶部摘要与自动展开项一致，用户可一步到达编辑入口。
- 左侧生成检查在通过时高度显著小于当前长列表，在有问题时仍提供准确的处理入口。
- 现有报告模板工作台前端单元测试覆盖折叠状态、问题优先展示和详情可达性。
