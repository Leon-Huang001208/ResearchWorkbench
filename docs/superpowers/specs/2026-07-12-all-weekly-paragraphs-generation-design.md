# 华安 ETF 周报全量段落生成优化设计

## 目标

统一优化华安 ETF 周报中全部占位符的生成职责、检索配置、Prompt 和输出结构，使各段落既保持一致的报告语言，又具备主题专属的事实范围、因果链条和关注重点。改造不把行业专属规则写入共用 Prompt，避免一个段落的调整污染其他段落。

## 占位符分类

周报共有 23 个占位符，按生成方式分为以下五类：

1. 字段占位符：`开始日期`、`结束日期`。由报告周期确定，不调用检索或模型。
2. Excel 固定回顾：`黄金市场回顾`、`原油市场回顾`。自动刷新 Wind Excel 后按固定句式生成，不调用模型。
3. 数据加分析：`A股市场回顾`。前半段读取 Excel 的指数与成交额，后半段使用 Evidence 分析市场热点与轮动。
4. Evidence 分析段：宏观、区域市场、行业、港股板块、黄金和原油，共 16 段。
5. 新闻快讯：`美国新闻`、`欧洲新闻`。只摘要最重要的一至两件事及直接影响。

## 共用约束与专属配置边界

共用 `generation_constraints` 只保留所有正文都适用的规则：

- 事实、数字、事件和观点必须有 Evidence 支撑；
- 只输出一个自然段，不输出标题、列表或分析过程；
- 不输出来源名称、Evidence 编号、引用编号、脚注或来源括号；
- 不编造数据、实体、政策表态或事件；
- 不输出投资建议、收益承诺、目标价、仓位建议或交易指令。

每个段落的 `retrieval`、`writing_structure` 和对应 Prompt 负责其专属规则：

- `subject_keywords`：主题锚点。候选材料至少命中一个主题词，防止只提到驱动变量却不讨论目标主题的材料进入候选池。
- `keywords`：驱动词。用于候选排序和重排，不作为必须逐项覆盖的写作清单。
- `exclude`：容易误召回的同名概念、长期泛论、广告或非目标领域内容。
- `writing_structure`：该段落的因果顺序和结尾关注项。
- Prompt：自然段要求、Evidence 边界、不得强行覆盖和该段的特殊禁区。

主题锚点负责候选精度，驱动词负责排序。系统保留共用 `top_k = 10`，候选池先保证主题相关，再由重排选择解释力最强的十条；材料不足时不使用弱相关内容补造事实。

## 各类段落结构

### A股市场回顾

保留现有“固定数据＋Evidence 分析”模式：

1. Excel 生成市场整体走势、主要指数表现和成交额变化；
2. Evidence 概括本周最重要的市场热点；
3. 说明板块轮动与风险偏好变化；
4. 结合一项有证据支持的政策、产业或景气变化给出审慎判断。

AI 部分不得重复指数和成交额数字。

### 宏观与区域

`中国宏观`、`美国`、`欧洲`、`日本`采用同一类逻辑骨架，但各自拥有独立主题锚点和政策变量：

1. 判断本周宏观或政策环境的主要变化；
2. 选择最重要的数据、政策决定或官员表态作为核心驱动；
3. 解释核心驱动如何影响增长、通胀、利率、汇率或风险偏好；
4. 根据 Evidence 补充财政、产业或外部风险，不强行覆盖全部维度；
5. 总结当前阶段，并给出后续二至四项关注变量。

专属范围：

- 中国宏观：国内增长、PMI、CPI、PPI、社融、货币政策、财政政策、房地产与产业政策。
- 美国：就业、通胀、消费、GDP、美联储、美元、美债和财政政策。
- 欧洲：欧元区增长与通胀、欧洲央行、欧元、财政与能源风险。
- 日本：工资与通胀、日本央行、日元、国债收益率和财政政策。

### 海外与港股市场

`海外市场`、`港股科技`、`港股央企红利`采用：

1. 概括本周市场或板块的方向与节奏；
2. 选择宏观、政策、资金或业绩中解释力最强的核心驱动；
3. 说明驱动如何传导至估值、风险偏好和板块表现；
4. 概括内部板块分化，只写 Evidence 支持的方向；
5. 总结行情性质并列出后续关注变量。

专属范围：

- 海外市场：美股、欧洲股市、日本股市、全球债券、美元及全球风险偏好。
- 港股科技：恒生科技、互联网平台、半导体、生物科技、汽车科技、南向资金与海外流动性。
- 港股央企红利：央企、高股息、银行、能源、通信、公用事业、利率与南向资金。

### 行业分析

`人工智能`、`电子`、`航天`、`电力设备新能源`、`消费`、`金融地产`、`医药生物`采用：

1. 首句提炼本周最重要的产业主线；
2. 选择供给、需求、政策、技术、价格或资本开支中最有解释力的核心变化；
3. 说明该变化如何影响产业链环节、订单、成本、渗透率或景气度；
4. 根据 Evidence 补充一至两个次要变化，不机械罗列公司新闻；
5. 总结行业所处阶段，并给出后续需要验证的变量。

各行业专属范围：

| 段落 | 主题锚点 | 主要驱动维度 |
| --- | --- | --- |
| 人工智能 | AI、人工智能、大模型、算力、数据中心 | 模型进展、算力资本开支、芯片与服务器供给、应用商业化、监管 |
| 电子 | 半导体、消费电子、电子元器件、PCB、存储 | 周期价格、库存、终端需求、先进制程、国产替代、资本开支 |
| 航天 | 商业航天、卫星、火箭、航天器、低轨通信 | 发射进展、订单、产能、技术验证、政策、卫星应用需求 |
| 电力设备新能源 | 光伏、风电、储能、电网、锂电、新能源车 | 装机与招标、产能与价格、出口、技术迭代、电网投资、政策 |
| 消费 | 社会消费、零售、食品饮料、家电、汽车、旅游 | 收入与信心、销量、价格、渠道库存、促消费政策、旺季需求 |
| 金融地产 | 银行、保险、券商、房地产、房企 | 利率与息差、信贷、资本市场活跃度、销售与投资、融资、政策 |
| 医药生物 | 创新药、医疗器械、CXO、生物科技、医疗服务 | 临床与审批、医保政策、授权交易、需求、价格、研发与商业化 |

行业段落不要求固定覆盖政策、技术、供需全部维度，只使用当周最重要且证据充分的因素。

### 商品分析

`黄金`和`原油`保留已经验证的独立结构：

- 黄金：走势—核心宏观驱动—美元/利率传导—央行或资金面辅助因素—后续关注。分析段不写价格、点位或涨跌幅数字。
- 原油：走势与交易主线—需求支撑与压制—供给与库存—地缘风险—后续关注。具体数字必须来自 Evidence，固定市场回顾数字不重复。

### 新闻快讯

`美国新闻`、`欧洲新闻`保持约 100 字：

1. 从本周 Evidence 中选择最重要的一至两件事；
2. 每件事只写事实及其对经济、政策或市场的直接影响；
3. 不扩展完整宏观分析，不罗列多条低重要性新闻；
4. 不写后续预测、投资建议或来源标记。

## Prompt 模板要求

每个 AI 占位符在 `prompt_templates.md` 中保留独立区块。区块包含两部分：

- 检索 Query：明确目标主题、时间范围和优先寻找的驱动因素；
- 写作要求：明确结构、主次关系、Evidence 边界、特殊禁区和结尾方式。

Prompt 不重复共用安全约束的全部文字，只补充该段独有要求。所有段落明确“驱动词是候选范围，不是必须逐项覆盖的清单”。

## 数据流

1. 生成任务先自动刷新并保存 Wind Excel；
2. 字段与 Excel 固定段确定性生成；
3. AI 段按各自 `subject_keywords` 检索主题材料；
4. `keywords` 对主题候选进行关键词与语义加权；
5. 本地重排器从候选池选择最多十条 Evidence；
6. 模型依据该段独立 Prompt 与 `writing_structure` 生成一个自然段；
7. 共用清洗逻辑移除内部分析过程、Evidence 标记和来源括号；
8. Word 投影写入各占位符。

## 错误处理

- 固定字段或 Excel 数据缺失：明确失败，不使用旧文本或 AI 猜测替代。
- 主题候选不足：只使用实际找到的相关材料，记录 Evidence 数量，不填充无关内容。
- Evidence 不足以支撑完整结构：省略缺证据的次要维度，保留事实和审慎总结。
- 模型输出分析过程、引用标记或列表：由共用清洗逻辑处理；清洗后无有效正文则记录 warning。
- 段落出现其他主题的专属实体：通过配置测试和真实抽样生成发现并修正主题锚点或排除词。

## 验证策略

### 配置完整性

为全部 19 个 AI 段落验证：

- 存在独立 Prompt 区块；
- 配置 `subject_keywords`；
- 配置驱动 `keywords`；
- 配置与段落类型匹配的 `writing_structure`；
- 未覆盖共用 `top_k = 10`；
- 专属词没有写入共用 `generation_constraints`。

新闻快讯允许使用简化结构，但必须配置主题锚点、重要性选择和直接影响要求。

### 逻辑回归

- 有主题锚点时，驱动相关但不讨论目标主题的材料被排除；
- 主题相关但缺少驱动词的材料仍可进入候选池，并以较低分参与重排；
- 聚焦摘录只保留包含主题锚点的相关句段；
- A股、黄金和原油的固定数据段继续走确定性分支。

### 真实生成抽样

至少抽样以下代表段落：

- 宏观：中国宏观、美国；
- 行业：人工智能、电子、医药生物；
- 市场：海外市场、港股科技；
- 快讯：美国新闻；
- 商品：黄金、原油。

检查每段是否具备清晰主线、因果传导、主题一致性、自然段格式和后续关注项，并确认没有 Evidence 编号、来源括号、标题、列表或投资建议。

## 非目标

- 不改变 Word 模板、图表布局或段落顺序；
- 不修改 Wind Excel 公式和数据口径；
- 不为每个段落增加独立模型或独立代码分支；
- 不要求每段机械使用十条 Evidence，也不为满足数量而加入弱相关事实；
- 不把本次周报专属行业规则推广到其他报告项目。
