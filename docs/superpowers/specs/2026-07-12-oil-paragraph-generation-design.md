# 原油周报段落生成优化设计

## 目标

将“原油”正文从新闻事项堆叠调整为因果链式周度点评，风格接近用户提供的理想样稿，同时继续遵守 Evidence 约束，不虚构具体事实、数字或事件。

## 配置边界

- `defaults.generation_constraints` 是所有段落共用的 Prompt 约束，只保留跨行业通用规则。
- 不在共用约束中加入库存、OPEC+、原油供需或地缘风险等原油专属要求。
- 原油专属要求只进入 `placeholders.原油.writing_structure`、`prompt_templates.md` 的 `原油`模板，以及石油关键词检索配置。
- 正文来源括号、Evidence 编号和引用编号的清理属于跨段落输出卫生规则，可以保持为通用后处理，但不得删除产品代码、百分比或单位括号。

## 生成结构

原油正文保持一个自然段，约 300 字，按以下因果链组织：

1. 判断本周油价方向及交易主线。
2. 说明需求端的主要支撑因素。
3. 说明需求端的主要压制因素或不确定性。
4. 分析供给、库存及 OPEC+ 政策变化。
5. 说明地缘风险及风险溢价变化。
6. 综合判断，并列出后续观察变量，不预测具体价格点位。

## Evidence 使用规则

- 只选择 3—5 条与本周国际油价直接相关的高质量材料，不为覆盖清单而拼接弱相关新闻。
- 具体数字、事件和政策必须有 Evidence 支撑。
- 材料不足时允许使用“需求预期仍存在不确定性”等定性连接与审慎判断，但不得补造库存数字、产量政策、价格点位或新事件。
- 排除长期航油需求预测、企业产品涨价、泛能源转型等不能直接解释本周国际油价的材料。
- 正文不得输出来源括号、引用编号、Evidence 编号、标题、列表或解释过程。

## 验收标准

- 共用 Prompt 约束不含任何原油专属词条。
- 原油段落呈现完整因果链，而不是逐项罗列新闻。
- 段落不出现来源型括号、`引用[n]` 或 `evidence n`。
- 具体事实可追溯到运行日志中的 Evidence；定性补足不引入新事实。
- 相关配置测试、生成测试和全文输出扫描通过。
