# 上下文配置锁定提示设计

## 目标

将启动环境变量覆盖的说明从系统配置主页面移除，只在用户实际遇到不可编辑的字段时给出非技术性的就地解释；同时保持后端对受管配置的强制保护。

## 非目标

- 不改变配置优先级、`.env` 持久化、启动参数或运行时环境变量的解析方式。
- 不新增配置 API、数据库结构、Redis 操作或桌面端 sidecar 行为。
- 不在普通配置流程中展示环境变量名称、锁定项计数或完整诊断名单。

## 用户体验

系统配置首页不再渲染 `environment_locked_fields` 的摘要、数量或字段名。健康总览和首次配置引导继续只描述“已就绪、待补齐、连接状态”。

用户打开某张配置卡片后，未被管理的字段保持现有编辑体验。受启动配置管理的字段进入只读状态，字段标签下显示：

> 此项由当前启动配置管理，不能在这里修改。

说明不包含 `DATABASE_URL`、`LLM_PROVIDER_1_API_KEY` 等内部名称。一个动态行的全部字段都被管理时，显示一条行级说明而非在每个控件下重复提示；关联的新增、删除、排序或编辑操作一并不可用。只有部分字段被管理时，仅锁定对应字段，其他字段保持可编辑。

当一个弹窗存在受管字段时，弹窗底部显示一次低干扰说明：“部分字段由当前启动方式固定。”不展示数量和名单。

## 前端实现边界

保留 API 快照中的 `environment_locked_fields`，但删除首页 `data-config-environment-lock-notice` 与 `renderEnvironmentLockedFields` 的全局说明渲染。新增单一的锁定元数据解析层，将表单控件、动态 Provider、任务路由及账号池操作映射到后端支持的配置键；该层产出字段级或行级的 `locked` 状态和无技术名的提示文案。

静态字段沿用已有 `applyEnvironmentLocks` 调用点，并扩展为同时设置 `disabled`、只读样式、锁图标、`aria-describedby` 和说明节点。动态列表在创建/回填行后应用同一元数据：大模型 Provider 按 `LLM_PROVIDER_{index}_{NAME|PROTOCOL|BASE_URL|API_KEY}` 映射，任务路由按 `TASK_{TASK}_PROVIDER` 与 `TASK_{TASK}_MODEL` 映射；账号池和联网 Key 池按其实际持久化键映射。无法建立完整一对一映射的集合不得伪装为可编辑，必须在集合级锁定并提供相同的友好说明。

## 数据流与安全

后端 `ConfigurationService._locked_fields()` 仍从启动环境覆盖计算受管键，并在保存事务中拒绝任何交集更新或删除。前端只消费脱敏的键名列表，不读取秘密值，也不向页面回填秘密值。前端锁定是可用性反馈；后端拒绝是不可绕过的安全与一致性边界。

保存操作遇到新的或过期的锁定状态时，继续显示现有结构化错误；前端随后刷新快照，以重新应用当前受管状态。连接测试不改变锁定状态。

## 可访问性与视觉规范

禁用控件关联到短说明的 `aria-describedby`；行级锁定说明使用可读文本，而非只依赖图标或颜色。视觉上使用低对比灰色锁标记、只读表单样式和轻量说明，不引入主页面横幅、告警色或动画。键盘焦点不会落在已禁用的提交/删除动作上。

## 验收与测试

1. 首页源码与实际界面均不显示“启动环境变量管理”、锁定项计数或内部配置键。
2. 高级配置、数据库、联网搜索的受管字段在弹窗中禁用并显示友好说明；未受管字段仍可编辑。
3. 全量受管的 Provider、任务路由或账号集合显示一次行级/集合级说明，并禁用会导致受管键删除或改写的动作。
4. 部分受管的动态行只禁用相关字段，其余字段可编辑。
5. 通过浏览器绕过禁用状态或直接调用 API 时，后端仍拒绝覆盖受管键；错误不泄露秘密值。
6. 静态前端回归覆盖首页无全局提示、字段/行级锁定挂点和可访问性属性；配置服务单元测试继续覆盖后端拒绝路径。
7. 在可用开发环境进行浏览器验证：打开含锁定字段的配置弹窗、检查键盘焦点与说明、保存未锁定字段、尝试受管字段的拒绝路径。

## 文件范围

- `app/web/templates/index.html`：移除首页环境锁定提示占位；在配置弹窗 footer 增加按需的低干扰说明挂点。
- `app/web/static/js/configuration.js`：以统一锁定元数据渲染字段级、行级和集合级状态；删除首页锁定名单渲染。
- `app/web/static/configuration.css` 与/或 `app/web/static/style.css`：补充只读、锁定说明和窄屏样式。
- `tests/unit/test_configuration_frontend_static.py`：更新首页提示契约并覆盖新锁定 UI 挂点。
- `tests/unit/test_configuration_service.py`：保留并必要时扩展环境覆盖拒绝与秘密值保护断言。
- `docs/modules/app_web.md`、`docs/CHANGELOG.md`：记录用户可见行为与前端锁定边界。
