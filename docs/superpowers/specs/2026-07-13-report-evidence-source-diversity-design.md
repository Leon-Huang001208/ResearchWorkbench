# 全源证据候选与来源均衡设计

## 目标

所有周报段落从全部已入库来源检索证据时，先按段落相关性形成候选池，再统一重排；不得先按入库时间截断全量材料，导致较早入库但高相关的中国证券网、快讯、知丘纪要、知丘公众号或其他来源失去入选机会。

## 当前问题

当前数据库检索先按 `created_at` 倒序取得固定数量候选，再执行段落主题、驱动词、语义与重排过滤。高频来源或最近入库的泛材料会占满候选池，其他来源中更早入库的高相关材料无法进入后续筛选。医药只是已观测到的案例，所有段落共用同一路径，均受影响。

## 设计

### 1. 全源相关性优先

不新增来源白名单，也不修改任何段落为仅使用某几个来源。所有来源均参与检索。数据库层先按段落主题词、驱动词和时间窗口过滤，再按全局相关性合并、去重并进入现有混合检索与本地重排。

### 2. 全局相关性候选池

为检索配置增加全局候选池策略：

- 保留现有总候选上限；
- 不按来源设置配额、保底数量或白名单；
- 全部来源的材料先按段落主题词、驱动词和时间窗口过滤，再按相关性进入同一个候选池；
- 不为没有相关材料的来源强塞证据；
- 同一文档去重后只保留一次。

最终选中的证据仍由现有主题约束、驱动词、时间过滤、语义分数与 reranker 决定，因此不会为了来源覆盖而降低段落相关性门槛。

### 3. 时间与主题边界

保留现有报告期过滤、未来事件标题排除、严格主题组、驱动词和段落特有边界。全局候选池不能绕过任何段落规则，也不能让医药、港股、美国新闻等段落重新混入泛市场材料。

### 4. 可观测性

在检索日志和运行记录中记录：检索到的来源分布、入池前后候选数量、最终入选来源分布。证据不足 warning 继续保留；它代表当前报告期内合格材料不足，而不是系统没有查询某个来源。

## 验收标准

1. 同一时间窗内，较早入库的高相关中国证券网或知丘材料可进入候选池，不会被较晚泛材料挤掉。
2. 低相关材料即使来自未覆盖来源，也不能绕过主题与驱动词门槛。
3. 所有现有段落仍使用全源检索；不得添加针对某个来源的硬白名单。
4. 医药、宏观、行业、市场、新闻各至少有一项回归测试覆盖全源相关性候选行为。
5. 最终真实抽检显示证据标题来源不再单一由最新入库来源主导；当合格材料确实不足时，保留明确 warning 和短文本降级。

## 非目标

- 不新增外部新闻供应商。
- 不改变 Excel/iFinD/Wind 的固定数据和市场回顾职责。
- 不承诺每个来源都必然进入每一段；相关性优先，不做来源配额。
