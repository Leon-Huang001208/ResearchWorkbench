# 极简系统配置编辑器设计

## 目标

将系统配置弹窗从多层强调、卡片嵌套和高密度描边中收敛为安静的表单编辑器。功能、环境锁定和秘密值安全保持不变。

## 视觉规则

- 删除弹窗顶部彩色线、分区图标、重复分区标题和卡片套卡片的容器边框。
- 页签只使用文字、底部分隔线和当前项 2px 指示，不使用背景块或额外图标。
- 集合行改为扁平表格：保留表头、一条外边框和行分隔；不为每个字段再绘制彩色外框。
- 输入框默认使用中性细边框，只有键盘或鼠标聚焦时显示主题色焦点环。
- 已配置密钥显示简短状态；“替换 / 清空”收敛为一个“管理密钥”入口，展开后才显示具体动作。
- Footer 仅保留取消和主保存按钮；测试连接移动为主按钮旁的低权重文字操作。状态消息占据左侧，不增加图标装饰。

## 交互与响应式

保持现有新增、编辑、保存、测试、环境锁定、秘密值替换/清空和未保存状态逻辑。桌面端维持紧凑表格；720px 以下改为单列字段组并显示字段标签。

## 验收

1. 弹窗内不再存在彩色顶部线、重复分区标题或字段级彩色容器。
2. 所有字段仍可编辑、聚焦和锁定；焦点可辨但默认视觉安静。
3. 密钥可通过单个入口管理，且不泄露已保存值。
4. 保存、取消、测试和错误反馈保持可用。
5. 前端静态测试和 JavaScript 语法检查通过。
