# 报告配置 B-A-C 连续优化设计

## 目标

在已完成的降噪工作台上，按用户确认的顺序改善三段真实操作流：编辑当前段落（B）、选择要编辑的段落（A）、完成配置并进入生成（C）。不调整左右栏骨架，不删除任何配置能力。

## B：当前段落更专注

- 顶部状态条只展示一个当前动作：缺 Query 时编辑 Query，缺关键词时编辑关键词；完成时展示可生成。
- “下一步”提示成为可点击的主操作，点击后打开相应的现有编辑区。
- 保存成功后在当前段落区域显示已保存反馈，避免用户不确定修改是否生效。
- 低频折叠区继续保留，不重新展开标签云或变量表。

## A：段落选择更直观

- 段落选择器按状态分组：需要处理、已完成、其他配置项。
- 每个选项显示可读标题、类型/来源和简短状态，而非只显示占位符名。
- 顶部补充“未完成 n 项”的快速入口，选择后跳到下一个未完成段落。
- 保持现有选择、切换和保存 API，不变更模板数据结构。

## C：完成到生成更清楚

- 配置进度条增加剩余项摘要；存在缺失项时，主按钮继续处理下一项。
- 全部完成时，主按钮切换为“查看生成前检查”，再引导到已有生成页。
- 保存、检查、生成三个状态使用同一消息区域，不在页面新增第二套流程。
- 检查失败仍由既有预检详情提供处理入口。

## 验收标准

- 用户在当前段落可一眼识别唯一下一步，并可直接进入编辑。
- 用户可从段落选择器区分需处理与已完成的段落，且无需阅读占位符内部名称。
- 配置全部完成后，用户知道下一步是检查或生成；未完成时知道剩余数量与目标。
- 所有现有编辑按钮、保存按钮、预检和生成 API 保持可用。
- 静态前端测试覆盖状态文本、状态分组、快速入口和完成后行动文案。
