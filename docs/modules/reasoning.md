# Module: reasoning

## Responsibility

`reasoning` provides evidence chain management, scenario analysis, skeptic validation, and reasoning traces.

---

## Design Rules

- Evidence chains should be auditable
- Scenarios should be comparable
- Skeptic checks should be explicit
- Reasoning traces should be reproducible
- Add or update tests when reasoning logic changes
