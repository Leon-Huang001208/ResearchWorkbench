# 全市场综合总览

本轮为 macOS 功能开发与 Mac mini Web 常驻部署，不涉及桌面安装包或其他平台原生验收。
用户已确认原型布局及“旧页面同页二级完整保留”。

## 导航与数据边界

普通首页和品牌链接进入 `#/market` 的综合总览。显式 `#/fingpt` 等旧链接保留原义。
`#/market?view=overview` 保留完整旧行情分析，`view=quotes` 与 `view=sectors` 保留
沪深北行情、板块与资金。研究工作台收纳既有事件、评分及研究操作，避免出现两个市场首页。

综合总览只读已保存的行情、事件与评分；刷新必须由用户明确触发，不在进入首页时开启
来源采集日程。九指数来自独立 `global-v1` 目录及缓存，与原 core-v1／terminal-v2 的
沪深指数响应并存。原始 OHLCV、未完成日线、行情时间和来源各自保留，缺少数据不绘制
虚构 K 线。具体身份、来源、价格指数与成交量单位限制见[九指数合同](research-web-global-indices.md)。

## 评分与时间线

时间线按日等距绘制，使用日期输入、今日和前后月份导航选日；起止日期用于改变视窗。
日期轴和事件行一起横向滚动，选中日期展示当日及持续事件、三地交易安排与来源覆盖。
只有明确「查看该日行情」才进入价格回放；缺所选日收盘时，前收只作单独参考。
迷你图用中性收盘线，提供日期、点位和区间变化，报价时间与最后已收盘日线分别显示。

研究工作台提供首批日历／宏观和评分证据的预检及明确执行。现有事件与六维接口扩充一次性操作，
复用个人仓库和不可变来源原件；预检不入库，重复标识不重复执行，单个来源失败时保留其余结果。
首批只覆盖本年度到未来十二个月的已公布安排；空白日期不推断休市或已发生结果。
先为上证综指、标普500、恒生指数保留可复算的趋势和风险原值，原值和合格研究分分开；
仅有日线、来源未准入或历史不足时不生成分数，不背填历史可知时间。

六维使用 `market-six-axis-v1` 冻结配置及服务端资格结果。历史运行列表不证明当前资格；
详情重新核验后的时间、证据与拒绝原因才可展示。原 A 股 `market-observed-v1` 描述性
温度分析继续位于行情分析，不转换成九指数六维分。没有生产启用回执时不展示正式总分，
缺维不填零、不填50、不重配权重。数据不合格、样本不足、验证失败和未启用分别标示。

时间线复用个人事件仓及不可变修订。默认过去30日至未来30日；日历与情景独立分行。
点击历史事件不改变当前行情。历史回放必须显式进入，只使用截止日已有价格记录；今日
取得的价格和事件不能因此获得历史时点资格。未来日期不显示虚构行情。

事件详情区分事实／来源、关联市场、窗口表现、历史统计及验证状态。没有已执行研究时
明确显示缺口，不以新闻方向或简单价格变化自造影响分值。
