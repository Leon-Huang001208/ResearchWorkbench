# 事件研究、日历效应与正式准入

该模块是 Host 内确定性计算，不创建第二研究引擎。文字解释仍由已有 DSH 研究链负责。首批研究身份固定为 SSE、CSI300、CHINEXT、SP500、NASDAQ、DJI、HSI、HSCEI、HSTECH；目录不是历史覆盖声明。

封存的实现摘要按固定相对路径排序，绑定 `event_studies/*.py`、`market_scoring/*.py`、
`event_host_inputs.py` 与 `event_datahub_bridge.py` 的逐文件字节SHA。开封前重新读取并比较；
缺文件或摘要变化在任何测试区间opened／compute claim之前拒绝。摘要不含mtime或环境绝对路径。
历史VALIDATED证书的正式评分消费也必须匹配同一实现摘要，不能把旧算法的验证授予新算法。

## 来源与研究

HTTP 仅接受已登记的不可变记录引用 `{id, revision}`，不接受价格数组、评分或客户端 PIT 标志。`StudyService` 从当前账号 `research.event_timeline.records` 解析 prices/calendar 和冻结事件引用，再由该领域的 `read_evidence` 校验原件哈希；原有 `research.events` SSE 会话字典保持原义。普通 DataHub 日线可做描述性研究，不能因保存到事件仓而变成正式回测数据。

默认Host生成的每个六维历史权重收据绑定精确factor_inputs ID／revision、已核验bundle摘要及
私有原件引用，并保留原信号known_at。缺来源引用或不是下一可成交开盘前已知的信号仍被拒绝。

指数描述性收益、匹配对照、交易日窗口及查看范围只使用明确的 index_rows/index_calendar 与指数来源哈希；ETF代理的价格、日期范围与日历不可替代。仅 proxy=None 的旧研究型指数输入保留 rows/calendar 兼容回退；带代理但缺指数证据时返回 index_evidence_missing。预检分别显示指数与代理覆盖，日历限制也分别记录，避免将代理历史标为指数历史。

缺正式交易日历时，可用真实价格日期计算描述性的星期/月/季/年窗口，明确显示 `observed_price_dates_only`，不推断缺失交易日、节假日或半日市。已核验日历才启用完整假期与复市跳空。正式回测要求 Host 专属 `resolve_event_study_bundle` 返回 `StudyBundle`，含历史资格收据、真实日历、精确代理、逐日交易规则与公司行动证据；缺适配就返回具体 `DATA_INELIGIBLE`，不启用新的供应商或真实模型调用。

节假日前后1/5/10交易日，完整假期跨越、复市开盘跳空；星期与月/季/年首尾1/5交易日；重大事件前后5/10日及事件期间。日期按交易所真实 session 划分，休市、半日市、DST、临时停市保留来源。Calendar.known_at 是取得时间；前瞻窗口另要求逐 session 的 known_at/announcement_version_ref，或有原件的整段公告时间/版本，不能将今日取得的未来交易日历回填成1990年已知。不同事件窗口重叠时标注，并合并成独立事件段供统计检验。同年普通窗口按事前20交易日趋势与波动匹配，不能按事后收益挑对照。

分钟精度的事件区间先投影到对应指数市场时区，再选择日线窗口；原始带时区区间、UTC区间、公布时间和冻结版本保留，NY夏令时及香港跨日不通过截取UTC日期猜测。日精度保留来源自然日，不补午夜；月精度不能构造精确日线窗口，保持明确不合格而不补当月第一天。

冻结研究与实时适用性共用 `events.project_event`，仅接收 day/minute 精度；interval、unknown、month、`event_time_eligible=false`、取消及情景均不投影。可知时间下界来自私有记录中该精确 revision 的 `created_at` 与对应原件 manifest 的取得时间，不能沿用修订前 payload.first_observed。若有可信下界，`known_at` 取下界与有效公布时间的较晚者；缺公布时间的未来日程仍可在实际取得后使用，只有历史公布日期而无版本取得证据则保持未知，不追认过去可得。

进行中事件未给结束日期时保留 `end=null/end_known=false`，不将开始日补成结束日。已知起点仍可计算前置窗口；赛事/冲突期间与结束后窗口必须等待真实终点，当前不产生这些窗口或实时分数。只选择未知终点之后的规则会明确返回 `event_end_unknown_for_selected_window`，不能凭默认结束日打开正式测试。

## 策略与验证

交易只做多与现金，信号产生后下一实际交易日开盘成交。代理实际上市前、无精确跟踪关系、未核验税费/手数/结算、不可知公司行动、无正式PIT价格均拒绝。基础佣金和滑点每边各10bp，再计入有日期和出处的税费。现金收益为零，双倍费用/滑点压力单列；账本用 Decimal，显示未结算款项，不使用当日收盘决定当日开盘成交。

六轴基准策略对同代理买入持有；事件/日历修正策略对冻结六轴基准。StudySpec 预先固定 family、direction（±1）和精确 rule；可描述一个 family 的全部预定窗口，但正式封存前必须选定精确规则。修正只在该规则窗口内贡献±1分，同 family 不重复，合计不超过±5分；回测由服务端编译此规则，不接受来源回调提供的无关最优策略。研究目标固定为风险收益改善，所有试验包括失败结果登记在 trial 中。

按时间60%训练、20%验证、20%一次性测试，跨边界20日标签剔除。封存必须含该 family 全部已登记试验；指标、数据、规则和程序版本固定后才打开测试集。正式批次全家族同步20session区块自助法10,000次、固定种子，事件段在多个市场/窗口间整体抽样，Holm家族错误率0.05。测试至少3完整自然年、30不重叠20日块；重大事件另需20独立事件段和5个自然年。

准入状态明确区分 `DATA_INELIGIBLE`、`INSUFFICIENT_SAMPLE`、`VALIDATION_FAILED`、`VALIDATED`。正式门要求费用后Sharpe改善且Holm调整p<0.05、净CAGR不低于比较策略、最大回撤不增加；双倍成本下仍须Sharpe改善且收益/回撤门成立。日历与重大事件都执行20独立事件段/5年的额外门；没有指数预测检验收据，不能单凭代理策略回测替代。门槛不保证必有合格因子，所有候选失败仍是有效研究结果。

指数预测检验由 `prediction.py` 独立计算，使用明确的 `index_rows/index_calendar/index_data_digest/index_qualification_receipts`，不将代理价格自动当成指数证据，也不接受适配器传入的“已通过”字符串。指数与代理各自按60/20/20封存，范围登记覆盖两套最终测试区间；指数配对的事件和对照收益端点都在其测试分区内，普通对照必须同年且在事件窗口开始前已经结束，只按当时可知的20交易日趋势/波动匹配。

预测窗口另执行 `known_by_window_start_price_v1`：按实际 session 的 start_price=close/open 确定起点时间，事件或日程必须在该价格时间之前已经可知，不能把其后才取得信息所对应的已实现收益称为预测。未知/晚取得窗口保留具体不合格原因；全部窗口不合格时为 DATA_INELIGIBLE，混合样本只对符合事前规则的窗口检验并保留排除清单。确定性日历要求对应边界公告在起点已知，不使用今日的日历取得时间替代。历史描述性表格仍保留这些窗口，代理实际成交检验另行执行。

同一事件、多市场重叠窗口及复用对照形成连通簇，按簇同步重采样10,000次。预先固定方向乘以“指数事件收益−匹配对照收益”，要求至少20个独立匹配簇、5个自然年，平均增量与单侧95%下界均为正，且全封存修正家族（含缺证/失败假设）的Holm校正p<0.05。独立收据绑定指数、规则、方向、数据/日历/来源收据哈希、profile与holdout，作为不可变 `admission` 和 `study_run` 的同事务产物；指数检验与代理策略均通过，外层才能准入。恢复后的资格对账屏障同时阻止封存、打开及最终提交，Host回调不能绕过。

复市跳空仍可描述和导出，但当前下一开盘成交协议无法买入已经发生的隔夜跳空，`reopening_gap` 正式封存/回测保持拒绝，不能把复市后收益冒充跳空收益。

评分验证绑定固定 profile、信号规则、执行规则、精确代理和来源合同的哈希；训练/测试原件哈希另行留作审计，不要求今天与历史数据字节相同。准入收据的起效时间不得早于实际验证时间与测试期末；当前候选数据和源权限仍须独立核验。修正的实时适用性还须由服务端当前日历/事件版本证明处于实际窗口，收据不会全年贡献分数。

查看全部历史描述性结果会以事务化 range claim 登记该段“已查看”，不能随后宣称同段是未见测试集。封存/打开使用跨进程原子范围占用，禁止切换日期或来源版本重用同一测试区间；未来不相交数据可新建试验。打开后崩溃或受理未知必须对账，不能自动重算；同一请求只有已有完整结果才返回幂等回执。

## 接口与验证

入口 `/api/research/event-studies` 提供目录/研究列表、创建、单项详情、preflight、analyze；`validation-batches` 封存家族，`validation-batches/{id}/evaluate` 一次性评估。写入需显式用户操作及幂等键，不提供后台自动评估入口。结果持久化为 `study_run`，评分消费者复核服务端 validation、report_digest 和完整证据身份，不能把 HTTP 测试成功当成业务准入。

`/{study_id}/runs` 读取有界运行摘要，`/runs/{run_id}` 读取冻结结果，`/runs/{run_id}/export?format=json|csv` 只从当前账号已存结果生成确定性导出，不重新分析或打开测试集。CSV沿用快照层公式注入转义；原始端点、公式、DataHub引用、来源哈希、交易日历限制保留，内部私有路径不导出。实际计算线程进入 `StudyService.activity()`；HTTP取消不能清除尚未排空的后台计算活动见证。

测试覆盖九指数身份、时区/交易日校验、固定窗口、前瞻泄漏、匹配对照、费用/结算/公司行动、回测守恒、样本门/多重检验、封存与范围重用。离线夹具只证明工程行为，不证明真实数据覆盖、真实源准入或生产部署。
