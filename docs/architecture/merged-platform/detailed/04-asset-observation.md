# 资产观察与提醒实施说明

## 统一资产模型

`AssetRef` 使用内部稳定 ID，`AssetIdentifier` 负责供应商代码映射。股票、指数、ETF、主动基金共享身份、来源、历史、事件和主题外壳，类型差异进入 `type_payload`，禁止复制四套详情页和事实表。

## 接口与同类规则

| API 组 | 功能 |
|---|---|
| `API-AST-001..004` | 搜索、详情、同类比较、资产事件 |
| `API-ALT-001..007` | Watchlist 与 Item 增删改查 |
| `API-ALT-008..014` | Alert Rule、Alert Event 和确认 |
| `API-NOT-001..002` | 持久化通知收件箱和已读状态 |

股票按申万细分行业，指数按类别，ETF 按跟踪指数或主题，主动基金按分类和基准形成 peer-set；响应返回规则、样本数和比较区间。

## 提醒状态

条件只在 `false → true` 时触发；持续满足按 cooldown 去重；恢复为 false 后产生 resolved。事实为 `stale/unavailable` 时不触发通知，而写入 `skipped_data_stale` 审计记录。通知先持久化到站内收件箱，再由 Tauri 桥接系统通知；桌面权限失败不能丢消息。
