# AlphaFoundry 合并平台产品品牌规范

本规范约束 Web 与 Tauri 共用的产品界面。它不保留旧 AlphaFoundry 的开发工具式视觉，而采用专业金融研究工作台：深海军蓝产品壳、浅色研究画布、高密度事实卡片、可追溯研究空间，以及相互独立的 FinGPT 与 Claw 入口。

## 设计原则

1. **事实优先**：市场、主题和资产页面先展示状态、时间、来源与质量标记，再展示解释。
2. **研究可追溯**：Evidence、Claim、Note 和 Artifact 始终回链 Research Run 与 Source。
3. **FinGPT / Claw 分工明确**：FinGPT 是即时单次研究伙伴；Claw 是有预算、步骤、团队和阻塞语义的多 Agent 任务台。
4. **同壳双端**：网页与 Tauri 使用同一页面结构和设计 token；桌面能力只通过适配层增强通知、文件和本地 Runtime。
5. **状态不伪装**：`stale`、`unavailable`、`quarantined`、`blocked_runtime` 等状态必须直接可见，不能用空白或虚构数据掩盖。

## 页面结构

- 顶部栏：品牌、全局搜索、研究空间、架构蓝图与用户入口。
- 产品导航：市场、主题、资产、FinGPT、Claw、自选、研究库、能力中心。
- 模块导航：当前产品域的页面、视图和最近工作。
- 主工作区：页面事实、研究任务或个人观察内容。
- 研究空间：来源、证据、Claims、笔记与产物的共享抽屉。

宽屏保留四区并列；中等宽度把研究空间改为抽屉；平板把模块导航与研究空间都改为抽屉；手机以主内容优先，使用底部产品导航，抽屉默认关闭。交互目标最小高度为 44px，并提供键盘焦点与 reduced-motion 支持。

## 参考边界

- AlphaEngine：参考专业金融产品壳、FinGPT 的中心输入区和 Claw 的任务工作台定位。
- Zhengyan：吸收问题驱动、来源可见、证据沉淀与研究回溯方式。
- 不复制参考产品的品牌、插画、文案、积分体系或具体视觉资产。

## 演示数据规则

原型中的市场数值均标记为“演示状态”，仅用于验证页面密度、状态表达和用户旅程。任何未接真实 API 的数值不得在实现阶段移除该标记，也不得被解释为实时行情或投资建议。
