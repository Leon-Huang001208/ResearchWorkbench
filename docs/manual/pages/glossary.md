## 数据与来源

| 术语 | 含义 |
| --- | --- |
| DataHub | 数据能力目录、来源选择、查询和快照的协调层。 |
| Capability / 数据能力 | 能完成哪类业务查询，例如市场行情或基金数据；不是某个供应商。 |
| Provider / 来源适配器 | 将业务查询翻译为具体来源调用并规范结果的实现。 |
| Dataset / 数据集 | 一次查询形成的可读取结果及其元数据。 |
| Snapshot / 冻结快照 | 保存本次实际使用的结果和来源信息，供复查和交接；不能自动证明历史时点可得。 |
| Manifest | 数据集的描述与文件记录，包括来源、范围、字段、缺失和限制。 |
| PIT | Point-in-time，历史时点可得性；下载时间或保存快照不等于已满足 PIT。 |

## 方法与接入

| 术语 | 含义 |
| --- | --- |
| Skill / 技能 | 完成任务的方法、输入要求与输出约定，依赖已声明的数据或工具能力。 |
| MCP | 客户端与工具服务之间的发现、认证和调用协议；不是一个数据来源的统称。 |
| 入站 MCP | 外部客户端调用 RWB 的获准能力。 |
| 上游金融 MCP | RWB 作为客户端调用外部来源，由 DataHub 的适配器接入。 |
| Registry / 安装 | 发现和管理 MCP 服务器的目录与实例，不等于工具已经可用。 |
| Grant / 授权 | 某个账号向某个应用授予的明确权限与材料范围。 |

## 如何组合

技能决定怎样做研究，DataHub 提供已授权的数据，MCP 决定怎样从外部连接或调用。三者的版本、权限与执行效果应分别核对。
