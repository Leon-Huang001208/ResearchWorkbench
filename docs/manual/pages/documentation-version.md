## 本版内容

文档中心按快速开始、任务指南、参考手册、架构设计和运维排错组织。
原架构图、API Atlas、API Manual 与原操作锚点继续保留去向。

## 结构定义的来源

API 参考使用同一份已发布 OpenAPI 契约快照生成分域页，当前记录460个操作、
457个业务参数说明与7个成功响应结构。未登记响应会明确标注，不能据此推断结果样例。

指南中的目录读取、技能查询和冻结材料发现取自已实现入口。调用例中的对象标识为占位符，
使用时必须替换成当前账号实际返回的值；本版没有为文档重演供应商取数或模型研究。

## 正在开发的接口

数据接口窗口的新来源、业务工具与字段口径，需要先确认版本、范围和验证样例。
草稿与候选不写成已上线能力；本版手册不会使已有授权自动增加。

## 如何更新

实现变化时，结构化定义随 schema/模型更新；任务步骤、业务语义、单位、限制和错误处理同步人工复核。
接口、使用指南和参考页应能互相到达，不维护独立且相互冲突的参数表。
