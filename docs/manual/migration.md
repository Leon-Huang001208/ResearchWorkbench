## 三条样板路径

- 首页 → 数据指南 → 数据字段口径 → DataHub/资产观察 API。
- 首页 → Skill 指南 → Skill 参考 → 能力中心 API。
- 首页 → MCP 指南 → MCP 工具参考 → 授权流程图/Registry API。

示例先覆盖已实现的目录读取、技能选择与冻结材料发现；不为写作重新取供应商数据或调用模型。
实操输出的业务记录与时点不能仅凭 schema 虚构，真实研究执行保持原资格要求。
