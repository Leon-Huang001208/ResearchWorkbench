## 观察与应用

首页先说明产品和发布状态，再列完整文档树；不以推荐卡片取代完整目录。
使用指南、API参考、开发说明是不同读法，通过顶栏切换。首页无左侧章节树，参考页有当前模块的左侧树。
右侧为本页锚点；版本、搜索、主题是阅读控件。RWB沿此结构，保留自身品牌、认证和隔离阅读实现，不新增Sphinx依赖。

模块页用于找对象：工具名/接口路径配一句用途，链接到详细说明。
详细参考按“签名 → 作用 → 参数及默认值 → 返回值 → 示例 → 错误/限制 → 相关指南”编写。
参数类型与结构取自实现，业务语义人工补充；未知返回结构明确未登记，不由示例反推schema。
本轮以 rwb_dataset_read 作为完整写法样本，partial的语义按实际实现说明，不误写成has_more。

规划与候选内容单列在架构设计，保留七个业务域和12工具目标设计；源码合并、部署和实际可调用分别说明。
