# Research Web 外观与主题

本页记录 2026-09-03 经用户确认的 Codex 风格正式 Web 外观，取代旧深蓝顶栏和双侧栏视觉方案。属于 **Redesign · Preserve**：改变布局和视觉，保留研究控制器、原生 DSH、路由、审批与下载契约。不引入原型脚本、演示目录或新的后端。

## 当前实现

| 模块 | 职责 |
| --- | --- |
| `app/research_web/ui/index.html` | 在样式加载前初始化主题；随后加载原组件样式和外观覆盖层 |
| `theme.js` | Light / Dark / System 偏好、本机系统变化、跨标签同步、存储失败降级 |
| `appearance.css` | 中性色语义变量、一级产品轨道、模式二级侧栏、设置分类栏、研究画布、抽屉、数据目录网格/来源矩阵、本机诊断列表、可选研究面板与品牌符号呈现 |
| `shell.mjs` | 在 68px 一级导航中保留产品入口，并把新研究、运行任务、最近研究及 Claw 工作空间放入 248px 模式二级侧栏；保留设置入口与符号 Logo |
| `app.mjs` | 使用真实研究数据组合页面；按路由加载研究台和只读监控；仅打开时显示活动/资料/文件面板；重渲染同步主题控件 |
| `settings.mjs` | 在产品壳内组合五个互斥的设置子页，并为桌面分类栏和窄屏横向标签提供稳定 DOM/ARIA 契约 |
| `workbench.mjs` / `asset-workspace.mjs` / `report-workflows.mjs` / `operations.mjs` | 研究台、独立资产观察、Claw 具体报告 Workflow，以及内容脱敏的用量、任务、DataHub、服务和存储投影 |
| `composer.mjs` / `capabilities.mjs` | 采用样品的紧凑入口、输入工具栏和三列能力卡；保留全部版本、输入与格式契约 |
| `icons.mjs` | 复用 v2 静态线性控件图标，未知名称安全回退；不解析外部 SVG |
| `core.mjs` / `views.mjs` | 继续维护原研究契约，不迁入设计原型的控制器或模拟数据 |

研究 API、存储和执行拓扑未变，架构图不需要虚构新的服务节点。主题是浏览器独立表现模块，不进入会话、Skill、DSH 或数据集。当前架构核对记录须识别本页和新增 `theme.js`、`appearance.css`。

## 布局和设计系统

- 桌面使用 68px 一级产品导航与 248px FinGPT/Claw 模式二级侧栏：一级只承担跨产品切换，二级承载当前模式的新研究、运行任务和最近研究；Claw 二级侧栏在“会话 / 工作空间”间切换。非 FinGPT/Claw 页面不渲染二级侧栏，底部保留设置与外观入口。
- 能力中心数据页在宽屏使用五项汇总、三列目录卡和来源矩阵；中等窗口依次收为三列/两列，手机为两列汇总与单列卡片。就绪状态颜色只表示对应维度，不把“代码存在”装饰成“可调用”。
- ≤1050px 导航变为抽屉；活动/资料/文件是另一独立抽屉。桌面研究面板按需展开，默认不占用聊天宽度。研究台筛选和监控时间范围在窄屏按内容换行，不隐藏查询、交接或未知值状态。
- FinGPT 和 Claw 首页使用最大 800px、左对齐的标题与编辑器（会话正文最大 820px）。附件、能力、输出格式与真实模型放在同一桌面工具栏，窄屏自然换行；首页四列入口、Claw 两列模板，能力中心三列紧凑卡片。能力入口继续来自 DSH 已保存目录。能力卡只带入草稿，不自动发起研究。
- 字体采用系统字体、PingFang；正文 16px、主标题 32px，4/8px 间距、8/10/16px 圆角。微交互 150ms，遵循减少动态效果偏好。
- Light：白色画布、暖灰侧栏、深色操作按钮；Dark：暖炭黑画布、浅色文字与操作按钮。错误、审批警告、成功分别保留语义颜色。

## 状态与安全

| 状态 | 语义 |
| --- | --- |
| 默认、hover、active | 由各主题语义变量控制，轻微底色变化 |
| focus | 清晰焦点环；原 skip link 和可访问标签保留 |
| disabled / loading | 保持控制器禁用行为；灰色且不被 hover 覆盖；不清空草稿 |
| danger / warning | 取消仍走原接口；审批说明、失败详情保持有色提示和可读正文 |
| MySQL 连接 | 沿用现有卡片、表单、徽标和 warning/danger 变量；密码不回填，手机输入和操作保持至少 44px |
| 系统变化 | 仅 System 模式跟随；手动 Light/Dark 不被系统覆盖 |
| 浏览器存储失败 | 当次仍能切换；记录固定事件名，不因 localStorage 抛错阻断初始化 |
| 刷新 / 重渲染 | 刷新恢复外观偏好；SSE 页面重绘后控件同步当前偏好；切换不重启研究 |

唯一新持久浏览器值为 `research-web.appearance.v1`，只允许 `light/dark/system`。不保存凭据、正文、用户文件或研究结果。前端日志仅固定事件名；验证程序将检查结果写入 `logs/research-web-appearance-*.json`。

## 验证入口

```bash
DSH_SOURCE_ROOT=/path/to/deepseek-harness node --test tests/javascript/research_web*.test.mjs
node --check app/research_web/ui/theme.js
node --check app/research_web/ui/app.mjs
node tests/e2e/research_web_appearance.mjs
node tests/e2e/research_web_appearance.mjs --live
```

浏览器检查需要本机已有 Playwright Core 和 Chrome，可通过 `PLAYWRIGHT_CORE_PATH`、`CHROME_PATH` 指定位置；不会安装依赖。默认模式仅将独立工作区静态文件覆盖到新建的测试浏览器，API 仍只读真实本地服务；`--live` 不覆盖静态文件，用于合入后验证正式 Web。所有非 GET/HEAD 及非本地请求被拒绝。不会触碰用户浏览器、提交模型请求、审批、停止任务或重启运行时。

## v2 样品还原核对

视觉基线为用户指定的 `codex-research-v2/index.html#fingpt`（本机 2026/09/03 的独立样品），不是 AlphaEngine 的旧双侧栏稿。第一轮仅替换配色仍保留了居中 Hero、大段卡片元数据和顶栏搜索，用户指出差异后已按样品重排。

在 1440×1000 下，样品标题起点 (448,214)、编辑器 (448,317.1875,800,162)、四卡起点 y=534.6875、高94px。正式页面新增几何回归，关键坐标/高度容差2px；这不是整页逐像素一致声明。实际会话、模型、能力名称/状态和审批不能复制预览占位内容。Dark Logo 以用户后续“白色图案”指令覆盖早期样品白底板。

浏览器修复回归记录：输出格式弹层样式必须限定 `.composer .format-options`，不得覆盖能力编辑器的同名常规字段；一级导航、模式侧栏和研究面板使用独立层叠上下文，避免抽屉或行级菜单遮住点击。

证据输出：`outputs/research-web-appearance/{isolated,live}/verification.json` 和同目录截图。实际结果在本轮 `.ai/reports/2026-09-03-research-web-appearance.md` 记录；这里的命令与状态要求不等同于已通过声明。

## 2026-09-06 可见性纠正

资产观察从研究台子页提升为主导航独立入口，仍使用同一 Codex 风格壳，并保留 OHLC K 线、MA/BOLL、成交量、成交额、换手率、MACD、KDJ、RSI 与细行情栏；图表只渲染 DataHub 返回的真实行情行，缺失时显示空态。成交额与换手率按 DataHub 的 `turnover` / `turnover_rate_pct` 分栏显示，任一缺失都保持未知，不以另一字段代填。Claw 首页新增具体报告 Workflow 区，能力中心 Workflow 页可查看其资源详情。两处都读取真实后端目录和区块状态，不复制旧 AlphaFoundry 的演示数据，也不把通用 Workflow 卡片当成华安 ETF 或创业板 50 报告。桌面保持工具型信息密度，窄屏允许行情图横向查看且其余区域自然收为单列；未发布或 `needs_attention` 项保持禁用而不是显示假成功。

## 2026-09-07 对话呈现与异常摘要

用户消息改为贴右的内容宽度气泡，桌面最大 78%，760px 以下最大 92%；助手继续使用左侧正文。可见头像及“你”/“Research Workbench”署名已删除，`article.message`、角色 class、Markdown 与流式更新容器保持不变。消息以不可见 ARIA 名称保留“用户消息”“FinGPT 回复”或“Claw 回复”语义。

会话异常横幅分别读取失败活动和异常 `subagents`，显示“7 项活动失败”或“2 项活动失败，1 个子 Agent 异常”等明确文案；零异常时不显示，历史失败明细与“查看详情”仍保留。本轮在 390、768、1280、1440 四档及深色主题完成只读浏览器检查。

会话重命名与删除收归二级侧栏的行级更多菜单，正文页不再保留独立重命名按钮。软删除项进入对应模式的“已删除”视图，保留 30 天并可恢复；用户也可二次确认立即永久删除。菜单和对话框沿用主题变量、44px 移动触控区、Escape／外部关闭与焦点返回规则，避免在窄抽屉中产生横向溢出。

## 2026-09-08 顶栏运行状态降噪

顶栏不再把健康的 DSH 连接状态作为常驻装饰，也不再提供语义过宽的全局刷新按钮。运行时健康且凭据有效时不渲染状态区域；缺少凭据、事件通道连接中和健康失败分别显示“需要配置模型”“研究服务连接中”“研究服务不可用”，点击进入设置。异常状态使用现有 warning/danger 变量，并在手机宽度保留完整文字和 44px 触控高度。设置、运行与用量及各业务页面继续展示完整诊断或各自的局部刷新入口。

## 2026-09-08 用户自配置 MySQL

设置页在原有设计系统内增加“连接与授权”，按模型服务、数据源、本机集成分组；不改变一级导航、字体、主色、圆角或卡片语言。MySQL 使用双列表单，窄屏收为单列；保存、取消、移除和前往检测均使用现有按钮组件，密码字段不可见、不可复制、不可回填。DataHub 来源详情复用既有徽标展示“未配置 → 已保存 → 已检测 → 可调用”，并在未完成时链接回设置。Wind、iFinD 与 Excel 只作为后续本机适配说明，不展示虚假开关或兼容结论。

## 2026-09-08 统一数据源连接中心

设置页将连接与授权改为“来源列表 + 同页详情”：22 个来源按专业数据源、API 数据源、公开来源和本机集成分组，列表同时呈现鉴权方式、配置、检测、适配和可调用状态。桌面维持左右分栏，860px 以下改为上下布局；来源按钮、输入框和操作按钮在窄屏保持至少 44px。模型服务保留为独立折叠区，不与 DataHub 凭据混存。

详情只展示来源真实支持的操作：MySQL、iFinD、知丘及 Token 型来源提供安全配置；Wind 只保存接入偏好并检测本机登录态；Excel 展示平台、自动化和插件诊断；无鉴权来源只允许检测；尚未适配的来源明确显示“尚未适配”，不展示无效提交表单。密码提交后立即从输入框和请求对象清除，GET 永不回填秘密。连接状态与深浅主题、键盘焦点、错误和加载样式均复用现有设计变量。

## 2026-09-09 设置分页

设置正文改为 Codex 式分类导航：通用、模型服务、数据源、本机集成和架构文档每次只渲染一页。桌面使用 200px 粘滞分类栏，普通表单限制阅读宽度，连接中心可使用剩余空间；760px 以下分类改为可横向滚动的 44px 触控标签。激活项使用 `aria-current="page"`，focus 和 reduced-motion 仍沿用现有变量。

数据源页只显示专业、API 和公开来源，并保留旧配置迁移；本机集成页只显示 Excel/Wind/iFinD 等本机诊断。模型配置不再使用折叠容器。刷新仅加载当前子页所需数据，通用与架构文档不显示无意义刷新。这些变化不改后端 API、凭据库、DataHub 或 Runtime 拓扑。

## 2026-09-09 数据源分类工作台

数据源页不再把 21 个远程来源同时展开为长列表。首屏以真实状态概览、专业/API/公开分类标签、搜索、状态筛选和紧凑卡片网格建立层级；空搜索结果保留恢复提示。“添加数据源”进入既有 DataHub 目录，不新建来源或绕过目录声明。

来源详情改为右侧粘滞面板，选择卡片时打开，关闭按钮或 Escape 只收起面板；切换分类会关闭不属于当前视图的详情。900px 以下详情顺序落到卡片之后，600px 以下概览改为 2×2、工具栏和卡片改为单列。颜色、凭据表单、状态语义、Hash 深链和所有配置/探测接口保持不变。

## 2026-09-09 本机集成诊断

本机集成页从“单项侧栏 + 四张等权状态卡”改为单列诊断流：总体可调用结论在首位，其后依次为 Excel 自动化、Wind 插件、iFinD 插件和报告工作流的环境检查，以及默认折叠的四阶段接入详情。只有多个本机能力组同时存在时才显示紧凑选择器，单来源不再占用空侧栏。

总体结论只读取来源的 `callable`、`integration_completed` 和探测状态；组件状态统一映射为环境已就绪、待检测、待验证、未安装、未登录、受限、异常或不适用，并明确声明组件证据不等于研究任务可调用。检测期间主操作保持禁用并显示进度，结束后刷新连接目录；失败、超时和格式异常沿用页面错误提示与安全日志。860px 以下诊断操作与检查项改为纵向布局，原生 `details/summary`、文字状态、焦点环、深浅主题和减少动态效果偏好保持可用。本次只调整现有 Web 设置页，不改变 DataHub、Runtime、API 或桌面交付边界。
