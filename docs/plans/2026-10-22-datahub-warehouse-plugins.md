# 能力中心、研究仓及插件基座实施

用户已批准完整方案；本文件记录执行顺序及权限边界。宿主 macOS，任务为功能开发。本机原生、适用 Docker Desktop 及同候选 GitHub Mac 安装分别取证；Windows/Linux 交接对应设备，不冒充通过。

## 已授权范围

- 独立 worktree 实现 DataHub 实际失败后的等价来源切换、总时限、真实工作占用、熔断和来源审计。
- 独立 PostgreSQL MarketStore、追加修订、历史时点、覆盖账本、冻结及开放格式恢复；DB 命中仍须服务器授权。
- 原始价格和因子分离；财务披露、更正、宏观修订及供应商资金流定义不得混用；不能用今日下载伪造历史可得版本。
- 修复已有来源，再接入独立公开来源。psycopg[binary]、既有测试工具与 baostock 仅本任务隔离环境安装已获批准；BaoStock 可做有界免费验证。免费优先，新增付费操作逐项确认。
- 在既有单 DSH 上实现审核固定版本及权限的插件生命周期；宿主不支持的组件明确拒绝，不能静默跳过。实际适配和授权检查须单独测试。

## 分段实施与证据

1. MarketStore 合同、PostgreSQL 索引投影、取消/提交边界、恢复及原始版本测试；独立规格和质量评审。
2. DataHub 执行可靠性、仓库读写衔接、来源口径修复及 BaoStock 适配；增量补库、实际授权和工具投影测试。
3. 仓库配置、Doctor、来源修复清单、有限真实免费样例与安装文档；各来源保留真实可用状态。
4. 插件格式、审核/权限、Skill/MCP/Commands/Agents/Hooks 的实际生命周期与受控空闲重启；独立评审。
5. 完整变更集合路由，本机必需验证、同候选 CI、受管提交/PR/合并。数据分支先交付，再交付插件分支。

## 保护及未授权操作

不连接/修改现有业务 PostgreSQL，不改现有服务或凭据，不启动全量采集。外盘当前 ExFAT 且无独立备份，本阶段不格式化、不迁移、不全量入库。正式数据根、业务数据库配置、部署、磁盘调整和其他新依赖另行授权。未来 NAS/服务器使用私网数据库服务及一致性导出恢复，不能共享打开活动数据库文件。

任务状态及命令结果记录在 `.ai/reports/2026-10-22-datahub-warehouse-PROGRESS.md`。未执行的浏览器、厂商、平台和 CI 检查保持 NOT_RUN；代码及单元测试不能替代真实来源验收。
