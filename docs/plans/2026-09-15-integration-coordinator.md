# 数据源与本机集成全量可用实施计划

## 交付策略

从每批开始时最新的 `origin/master` 创建隔离 worktree，按
`start → implement/commit → prepare → publish → poll CI → cleanup` 交付。每批只在实测验收与 CI
均通过后关闭；缺少账号、许可、额度或经批准依赖时保持未完成。

## 批次

1. **检测底座与状态页**：统一契约、原子快照、启动/手动批次、授权、错误归因、Tabbit 双状态、
   15 个常驻 DataHub 工具和旧接口兼容。
2. **现有 Provider 闭环**：天软、AKShare、MySQL、财联社、东方财富基金的探测、查询、快照和
   Runtime 调用。
3. **专业数据源**：Wind 与 iFinD 的行情、财务、指数、资金和宏观能力。
4. **公共市场与监管**：BaoStock、Yahoo、ChinaStock、中证指数、深交所、巨潮资讯。
5. **资讯、研报与搜索**：中国证券网、知丘三类来源、Tushare、Tavily、Bing。
6. **本机生产力**：Excel、Word、PowerPoint、Wind Excel 与 Tabbit 的一次授权后隔离验证。
7. **双向文件同步**：受控根目录、八类文件、启动对账、事件防抖和保留两版的冲突队列。
8. **本地 MCP**：安全摘要发现、逐 Server/Tool 授权、固定版本或摘要校验和受控真实调用。

## 批次 1 验收

- 协调器覆盖启动恢复、原子写入、指纹失效、批次去重、超时/取消、并发上限和授权撤销。
- 新 API 返回五类汇总、五阶段状态、最近尝试/成功及问题责任；兼容接口仍通过。
- 设置页“刷新状态”创建真实探测批次并展示进度；未交付能力不再计入用户责任。
- Tabbit 同时展示已保存配置、Runtime 已应用配置和是否需要重启。
- 15 个 DataHub 工具始终注册，Broker 仍负责动态选源与禁止的回退语义。
- Python、JavaScript、架构检查、文档同步检查与本机浏览器验收通过；状态和日志不含秘密。

## 外部与依赖门禁

安装或新增 `akshare`、`cjpy`、`baostock`、`yfinance`、`tushare`、Office 或文件监视依赖前，逐项
说明用途、影响和目标文件并取得明确授权。收费/登录/厂商来源在首次自动探测前逐来源授权；Mac
执行真实冒烟，Windows 以原生 CI 交付，不把 CI 模拟器写成真实桌面实测。
