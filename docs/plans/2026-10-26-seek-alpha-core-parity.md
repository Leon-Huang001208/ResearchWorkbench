# RWB 核心研究工作台功能对齐实施计划

用户批准：2026-10-26。以 62 个 Skill、78 个 MCP 工具和已观察的页面为冻结对照基线，按功能与操作闭环验收，融入现有 RWB 视觉和唯一 DSH。

## 全局约束

- Host → DataHub／受管 MCP → 唯一 DSH → Host 质量核验 → Report Workflow；不新增第二研究引擎、聊天正文库或任意 MCP URL 通道。
- 浏览和准备草稿不启动模型；实际发送沿现有用户动作及服务端鉴权。证券身份、账户、截止时点、证据版本与原件 Hash 必须保持。
- 自有实现与小创原源分别评估和标明来源。专有形态／评分、私有研报、供应商授权和真实 schema 的缺口不可伪造。
- 音频转写、录音纪要不实施。文档翻译、资料解读和现有文件／成果管理保留。
- 新依赖、秘密、收费实测、真实模型研究、常驻部署分别授权；本次源码授权不自动包含这些动作。不得触碰现有业务数据或停止服务。
- 复用现有能力，卡片／声明／提示词不等于功能完成；逐项记录已实现、数据依赖、测试、未验收和阻断。
- macOS Web 功能开发；完整 changed set 的 Router、独立评审、原通用 CI 和同候选 macOS 干净安装；其他平台交接。

## 范围与交付顺序

1. 三大页面联动：个股（概况、行情、财务估值、研究摘要、同业、产业交叉、资料、新闻）、资讯（来源／分类／时间／重要性／搜索／热门／自选／选段）、FinGPT／Claw（场景、Skill、上下文、来源、追问、成果）。首批八场景：公司一页纸、行业一页纸、基本面、技术面、新闻查询、新闻传导、调研大纲、历史复盘。
2. 逐项补全 62 Skill／78 Tool 映射及九包：持仓排雷、预期差、短线情绪、调研前置、事件复盘、海内外舆情、估值体检、筹码结构、财报季前瞻。原源 MCP 离线适配并行评估，真实 Registry／凭据／付费授权缺失保持阻断。
3. 深研与角色：公司十维、财务三维、行业五章；版本化行业专家／投资风格；2—8 角色观点、分歧、来源与综述；进度、部分失败、取消及质量核验。
4. 资料与跟踪：文档翻译、底稿／报告输出、自选导入、资料组织、变化检测和默认关闭的计划；便民工具后置独立记录。

## 实施任务

- T1：冻结 62／78 基线和可机器读取的逐项映射，提供首批八场景合同；测试覆盖完整计数、唯一身份、不可冒充可调用及专有依赖。
- T2：完成第一批三大页面联动及实际 Host 上下文／证据交接，八场景接真实能力与工具；覆盖来源选择、草稿、发送、结果和归档路径。
- T3：补全其余 Skill／Tool 和九组合包的方法、参数、工具、数据与产物合同，提供可运行确定性计算／查询及缺数据用例。
- T4：使用既有 DSH／Report Workflow 实现多维深研和角色／圆桌，保留各子任务证据与状态。
- T5：补齐文档翻译、自选／文件组织和跟踪模板，保持显式启用、变化检测、未知不重发。
- T6：按每批完整变更集完成 Router、回归、浏览器、独评、同候选 CI、受管交付和安全收尾。依赖阻断与上线状态单列。

## 验收

每项映射原站入口、输入输出、RWB 执行路径、来源／费用／覆盖、实际验证；不以待配置作为通过。新增场景覆盖成功、缺数据和失败。反例包括证券误配、负增长、历史时点缺失、无出处产业关系、新闻重复／冲突、持仓截断、评分不可复算、跨账户和撤权。Agent 覆盖取消／断流／部分失败／重启／未知受理。UI 覆盖空／加载／错误／过期／权限／长文本／键盘／窄屏；登录态实际页面和费用／模型质量分别取证。

## 控制副本与证据

原工作区的 Git 读取被 macOS dataless 引用和旧 worktree 元数据阻塞。保留原目录与全部旧资源，从 GitHub 建立本任务独立控制副本，已通过完整 fsck，之后使用原受管 Git 入口创建任务工作树；未复制或覆盖旧源码／业务数据。
研究输入为 /tmp 中 2026-10-26 的已观察公开目录、62 技能名、公开前端静态分析及只读 UI 记录。只冻结公开目录／名称与脱敏方法摘要，不提交账号资料、余额、私有页面正文或秘密。
