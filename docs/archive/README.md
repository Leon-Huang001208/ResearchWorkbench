# Research Workbench 历史归档

> **状态：historical**。本目录只用于追溯当时的方案、实现和验收，不是当前启动、架构、接口、支持范围或操作命令的权威来源。现役文档从 [`docs/README.md`](../README.md) 进入。

## 分类

- `legacy/`：旧单体架构、文件指南、参考手册、数据源、数据库灾备和早期 Research Web 实施记录。
- `architecture/`：已被当前 Research Web 架构取代的 merged-platform 蓝图及图源。
- `implementation/`：已完成或被替代的设计、计划和 Issue 实施摘要。
- `tasks/`：原 `tasks/active` 中已经完成的任务记录及过期待办。
- `acceptance/`：日期型真实验收快照；只证明当时指定环境和路径。
- `reviews/`：累计式架构评审历史。
- `research/`：一次性研究材料，不代表已采用的产品决策。
- 根目录原有文件：更早的实现计划、设计、用法、里程碑和临时报告。

归档文件原则上保持原文，便于审计。若归档内容与当前代码冲突，以当前代码、测试、配置和现役文档为准。
