# 文件指南已退役

旧文件级手册会复制目录树和实现细节，已无法可靠反映快速变化的源码。其历史版本保存在 [归档](archive/legacy/file-guide.md)。

请改用：

- [文档门户](README.md)：按受众和职责查找现役文档。
- [Development Map](DEVELOPMENT_MAP.md)：按源码区域查权威文档、测试和更新触发器。
- [生成的 Python 文件索引](generated/py_file_index.md)：查类、函数、导入和文件位置。
- `rg --files`、`rg <symbol>`：查询当前实际源码。

本兼容入口不再维护逐文件说明，也不是任何主题的权威来源。
