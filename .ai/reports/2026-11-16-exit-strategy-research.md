## 实现

- 研究专用配置、明确上传和运行、数据及回执冻结。
- 计算放量滞涨及 5、10、20 日均线收盘破位，返回两类胜率、收益差及同日最近邻配对。
- 逐笔显示触发证券和相似对照，读写以请求所解析的账号根为准。

## 本机结果

受管 WIP 批次跑过引擎/API 11 项、协议 81 项及本机集成 107 项。Node 策略、导航和相邻页面 41 项通过，主 UI/能力 89 项通过。收尾用项目测试入口核对 JUnit 与进程退出码。引擎参数化初批的 10 项实际通过，登记的 node IDs 计数与 JUnit 不符，原输出留存后在同一根真实重跑并正式回收。

Chrome 通过隔离真实 Web Host 上传前轮冻结输入，归档 SHA-256 为 `10877827ea5dc42f24eebea2e9d4eae6cce61a75809de1baffb6abfe22c98113`。Host 计算 160 只股票、200,820 条日线，四条规则合计 49,863 条触发。数据库原子读回各规则、历史参数、分母和对照。逐笔页显示触发股票、对照股票、对照收益和范围内分页；继续由浏览器把期限改为十日并选择放量滞涨，独立生成 892 对、1,053 个可比较卖出事件的第二项运行，第一个运行保持其原参数。

## 首次远端检查与修补

首次集成候选 `444a0a25` 的 macOS 15 Bootstrap 和 Project Constraints 通过，Research Web Checks 的三项服务管理器静态资源边界断言失败。候选 `app.mjs` 为 260,995 字节，合同要求在 256 KiB 读取上限下保留 2 KiB 余量。三项均为共用产品资源字节门。研究冻结输入、计算结果和用户配置不参与此失败。修补将策略页面的装配、路由映射和事件委托收入已有的页面模块结构，原静态资源上限保留。修补后资源为 259,688 字节，比 260,096 合同门低 408 字节，定点三项通过。事件、评分、策略和 ETF 入口的 Node 回归 81 项通过。Chrome 验收使用附着到当前输入元素的真实冻结文件内容触发选择，避免测试驱动的远程文件选择与页面重绘竞争。

## 交付边界

GitHub 通用与 macOS CI 的实际候选证明使用仓库交付回执记录。Windows 原生执行由对应设备接手。常驻版本切换、账号迁移专项保全及生产安装验收另有受管流程。策略、配对和收益公开为历史研究，真实 PIT 未验证。
