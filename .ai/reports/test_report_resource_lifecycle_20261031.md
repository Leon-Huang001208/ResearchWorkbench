# Event-driven development artifact lifecycle

Host: macOS. Task: shared engineering resource governance and RWB closeout
integration. Product deployment, Windows/Linux native acceptance and historical
unclassified backup deletion are outside this source change.

## Behavior and structure

The existing Git safety entrypoint retains its review, branch protection,
restore verification, identity, occupancy and Docker disposal checks. After
those checks finish, a small bridge calls the verified shared lifecycle kernel.
The bridge registers this task's verified temporary evidence and contributes
the existing BuildKit measurement to the host cache budget. Cleanup debt is
separate from source delivery; it cannot certify a pending cleanup as cleaned.

Ordinary recovery points registered by completed deliveries rotate on later
lifecycle events without a seven-day wait, while the latest two valid points,
unmerged work, unique anchors, unknown legacy points and repair isolation remain
protected. This does not run Git object maintenance or change a business service.

## Observed validation

- macOS candidate: 468 Node contracts passed, including original Git safety,
  prepared-revision recovery and validation-policy contracts.
- Python protocol smoke: all 81 cases passed using an isolated, explicitly
  authorized pytest/pytest-asyncio environment and existing runtime dependencies.
- Documentation governance, generated Python file index and whitespace checks
  passed. The first CI exposed missing module documentation and this structure
  decision report; both are now included without weakening the checker.
- Shared framework candidate adds host resource leases, staged deletion,
  bounded summaries and deployment-generation replay protection. Its macOS
  suite has 337 passing cases; generic CI explicitly retains originals when
  native occupancy is unknown and uses a closed fixture for retirement logic.

## Evidence boundaries

The final repaired candidate requires fresh Project Constraints CI. No prior
failed or cancelled run is certified as passing. Shared framework publication,
managed local installation and event activation are individually checked;
source presence alone does not prove activation. Historical inventory remains
pending category approval. Native acceptance on other devices remains NOT_RUN.
