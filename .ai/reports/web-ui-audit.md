## 设计特色

### VS Code 风格界面
- **活动栏 (Activity Bar)**: 左侧图标导航，12个功能入口
- **状态栏 (Status Bar)**: Git分支、错误/警告计数、数据库状态、LLM提供商、文档计数、语言
- **设置弹窗**: 级联菜单，支持主题/语言/配色方案切换

### 主题系统
- 亮色主题 (Light)
- 暗色主题 (Dark)
- 5种配色方案:
  - VS Code (默认蓝色)
  - GitHub (绿色)
  - OpenClaw (红色)
  - Claude (橙色)
  - Obsidian (紫色)

### 国际化 (i18n)
- 中文 / 英文双语支持
- 所有UI文本可翻译

### 图表集成
- **Chart.js 4.4.7**: K线图、饼图、概率分布图
- **D3.js 7**: 力导向产业链图谱

### 组件库
- 卡片 (Cards)
- 数据表格 (Data Tables)
- 表单 (Forms)
- 标签页 (Tabs)
- Toast通知
- 加载状态
- 下拉菜单
- 筛选器
