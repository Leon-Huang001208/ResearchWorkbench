# 遗留备份锁恢复与工作树设备身份复核

本任务是 macOS 的 Git 交付维护。复用已有的 v2 备份、Git common directory 所有权、
仓库锁与备份锁。无需访问业务数据、改动线上服务或执行模型比较。Linux CI 只运行隔离验证，
不代表 Linux 或 Windows 产品验收。

## 结构决策

在既有 Git 安全 CLI 增加显式、默认只读的入口。遗留锁只能在原退出证据、不可用的旧进程组
及独立恢复由项目确认后保留式归档。不完整快照不被认证，也不删除。历史工作树的设备身份复核
仅在已合并证明和备份内容完全匹配时更新资源账本设备号。保留历史回执原件和改写前账本。
普通交付、容量、Git 和运行资源的门槛维持原样。

## 验证证据

隔离用例验证了真实 v2 恢复、损坏备份、活跃持有者、丢失仓库锁、并行恢复、过期摘要、权限
漂移和已登记目录重现。Mac 本机定点验证通过；历史 #258 备份另经同一恢复入口实际恢复，
Git 完整性检查通过。此验证没有修改 #258 现场。

首轮 CI 暴露 Linux 文件时间与用户态时间的毫秒差。修正方式是显式设置测试夹具的因果顺序，
生产约束没有放宽。第二轮测试阶段通过，最终约束步骤要求指定模块说明与结构复核原件；
本报告同步这两项并保留先前 CI 结果。新候选须重新跑原 Project Constraints 和 Mac 检查。
