# 市场解读

1. 明确市场、观察区间、截止时间与输出口径。先检查当前会话已有 DataHub 数据集；不足且 Runtime 已暴露 `datahub_search_news` 时，由父 Agent 直接调用。Runtime 只暴露启动时已有可调用来源的 `datahub_*` 工具；已配置且可用的来源自动执行，不逐次确认。工具未暴露时不调用、不重试，并明确数据缺口；子 Agent 复用父 Agent 已取得的数据集，不重复取数。
2. 读取 `inputs/datasets` 下的 manifest 和结构化数据，核对 `dataset_id`、`manifest_sha256`、来源、`retrieved_at`、实际覆盖、分页状态、缺失与限制。数据不足时明确缩小结论范围，不补造行情或事件。
3. 如需筛选大量资讯，可使用 `research_run_script` 运行随包脚本：按发布时间、来源、可核对性和市场影响关键词进行透明排序。排序只是研究辅助，不等同于投资结论。
4. 将事实、来源原文摘要和分析判断分开。每个数字注明日期、单位及来源；无法从快照核对的内容标为待验证。
5. 需要文件时，使用 `templates/report.md` 和 `scripts/workflow.py` 生成 DOCX、HTML、XLSX。三种文件必须引用同一数据集编号、哈希和截止时间；文件未生成则说明未完成原因。
6. 返回实际文件名、主要市场事件、可能影响、反向证据、数据缺口与下一步核对项。不提供个性化交易指令。
