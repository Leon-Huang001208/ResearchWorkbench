# 宏观与跨资产

1. 明确经济体、制度背景、政策工具、观察窗口、资产范围和分析截止时间。本能力限定宏观制度、政策、流动性与跨资产传导，不处理单一公司基本面、产业链全景或日常资讯汇总。
2. 按 `references/evidence-protocol.md` 优先核验政策原文、官方统计、央行或财政机构资料和可复核市场数据。`web_search` 只发现来源；决定性原文或数据不可访问时，写明“证据不足”或“无法判断”。
3. 区分政策宣布、实施、资金流动和资产反应的日期，统一频率、单位、币种、名义/实际与季调口径。建立事件前政策预期、流动性和资产定价基线。
4. 分析“制度约束或政策 → 流动性/增长/通胀/风险溢价 → 利率与汇率 → 股票、信用和商品”的条件化链条。每一跳注明证据、假设、时滞和替代解释；不能验证时缩短链条。
5. 并列处理增长与通胀信号冲突、政策目标冲突和不同期限资产反应。给出基准、再通胀、衰退或流动性收紧等适用情景时，列触发条件、观察指标与失效信号，不编造精确概率。
6. 默认在聊天中交付制度与政策背景、证据表、跨资产矩阵、冲突、情景和待核查项。只有用户明确要求文件且当前 Runtime 暴露文件工具时才生成并核验产物。
7. 输出非个性化研究判断，不把跨资产含义转成个人配置或交易指令。
