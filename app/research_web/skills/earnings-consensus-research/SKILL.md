# 业绩与一致预期

1. 核实公司或证券身份、报告期、披露时间、财务口径和分析截止时间。本能力只回答业绩、指引、预期差与机构分歧；完整公司画像应使用公司研究能力。
2. 按 `references/evidence-protocol.md` 优先读取法定披露、业绩材料和管理层原文，再核对有日期与样本说明的公开一致预期。`web_search` 摘要只作线索，不能代替财报或一致预期数据。
3. 将收入、利润、利润率、现金流、分部和经营指标与明确基线比较。每个“超预期”或“不及预期”都注明指标、预期值、实际值、币种、口径、预期采集时间和来源。
4. 缺少可靠一致预期时，不推断超预期幅度；改为与公司指引、上一报告期或可比历史口径比较，并明确“缺一致预期，无法判断市场预期差”。
5. 区分已披露事实、管理层观点、新增证据和研究推断。梳理指引变化、机构分歧、一次性项目、会计口径变化、反向证据及下一验证节点。
6. 默认在聊天中交付业绩桥、指引变化、预期差、分歧、风险与待核查项。只有用户明确要求文件且当前 Runtime 暴露文件工具时才生成并核验产物。
7. 只给条件化、非个性化研究判断，不根据个人情况给出仓位或交易建议。
