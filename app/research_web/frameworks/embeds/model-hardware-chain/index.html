传导链：一次模型优化如何变成硬件订单

以 GPT-6 的 105 万 token 上下文为例做全链条推演：上下文每延长 10 倍，KV Cache 显存占用近似线性增长 → 单并发所需 HBM 容量与带宽跳升 → 单卡 288GB HBM4/22TB/s 成为 Rubin 的入场券 → HBM4 晶圆消耗是标准 DRAM 的 3-4 倍 → SK 海力士喊出"4-5 年短缺"、存储原厂集体提价 → DRAM 合约价 2026Q1 +90~95%、Q2 再涨 58~63% → 美光 YTD +225%、闪迪 +545%。模型层的一个架构决策，在 6 个月后以存储原厂利润表的形式兑现——这正是"每次模型优化背后都是硬件需求激增"的微观机制。

另一条链：推理 effort 分档（GPT-6 的 low→max 四档）让"智能"首次成为可按需购买的连续变量。Max 档推理消耗可达 low 档的 10-50 倍 token → 推理算力弹性系数远大于 1 → Lisa Su 直言 2026 年 AI 算力 60% 用于推理 → GB300 NVL72 出货排满、CoreWeave 时租 $10.5/GPU 依然满载 → 训练:推理开支从 2025 年的 70:30 翻转至 2026 年的 30:70。

02

双假说对抗验证

DEFLATION vs EXPLOSION

假说 A：优化即通缩

  • 价格自由落体：推理价格中位数年降约 50 倍（2024 后达 200 倍/年），前沿智能价格指数从 100（2023-03）跌至 5.5（2026）
  • 架构红利：MoE 激活参数占比降至 2-5%；MLA 把 KV Cache 压缩 90%+；FP8→FP4 量化再砍一半成本
  • DeepSeek 冲击：R1 证明顶级推理可被低成本复现，NVDA 单日 -17% 即市场对该假说的定价
  • 开源替代：OpenRouter 开源份额 60%+，闭源溢价被持续压缩
VS

假说 B：需求爆炸（Jevons）

  • 用量弹性 >> 价格通缩：中国日均 token 1000亿(2024初)→170万亿(2026-05)；Google 月处理 320 万万亿 token（年增 7 倍）
  • Agent 渗透率仅约 8%：测算显示 Agent 每渗透一个量级，token 消耗存在再增 5 倍的潜力
  • Test-time Compute：推理深度成为新 scaling law，单查询 token 消耗结构性上移
  • 资本开支不减反增：2026 年九大 CSP 资本开支 $8300亿（+79%），占经营现金流 94%

◈ 裁决：Jevons 悖论阶段性胜出，但通缩在重塑"谁受益"

两个假说同时为真，只是作用于不同环节：单位经济学通缩，总量经济学爆炸。输家是"卖 token"的模型 API（毛利率被开源与价格战压缩），赢家是"卖铲子"的硬件链——因为需求弹性把效率红利全部转化为算力采购。但通缩并非无害：它逼迫硬件链向极致性价比迁移——FP4 精度、HBM4 带宽、1.6T 光互联、电源液冷一体化，每一代硬件的"降本指标"权重首次超过"性能指标"。DeepSeek 冲击那天蒸发的 $6000亿并未消失，而是在三个月后以更陡峭的曲线回归——这就是 Jevons 的市场形态。

一次推理的两个世界：Prefill 算力受限 × Decode 带宽受限

PREFILL · 读入提示词
算力利用率高
带宽利用率低

并行处理全部输入 token，矩阵乘拉满 FLOPs。GPT-6 的 105 万上下文让 Prefill 成本随长度超线性上升 → 推动稀疏注意力与长文本专用优化。

⇄
DECODE · 逐字生成
算力利用率低
带宽利用率瓶颈

每生成 1 个 token 都要把全部权重+KV Cache 从显存搬一遍，吞吐被 HBM 带宽锁死。上下文越长 KV Cache 越大 → 内存带宽成为推理 TCO 的第一变量。

PD 分离的本质：把两类负载拆到不同的资源池各自配平——这正是 HBM、NVLink、光互联涨幅跑赢纯算力标的的微观结构原因。

上下文窗口膨胀 → KV Cache 压力（对数轴）

上下文从 4K 膨胀到 105 万（约 260 倍），KV Cache 显存占用近似线性增长；每 token 的 KV 字节数被 MLA/GQA 压缩，但窗口膨胀速度远超压缩速度——净效应是 HBM 容量需求持续上修。

优化栈 → 硬件需求 · 桑基图（流量宽度 = 需求传导强度）

读法：左侧四层优化（架构/量化/引擎/调度）的每一项"降本"动作，都在右侧汇成某个硬件环节的"增需"流量。HBM 与光互联是最粗的汇入点——带宽环节承接了最多优化动作的反弹需求。

单卡推理吞吐代际跃迁（tok/s，InferenceX 实测口径）

代际增益主要来自 HBM 代际（3→3e→4）与精度革命（FP8→FP4），而非算力堆叠——再次印证"带宽>算力"是本轮硬件周期的定价主线。

GPT-6 时代的前沿信号（2026-09-16 快照）

模型侧：GPT-6 Astra（$10/$50 每百万 token，缓存 $1）以 105 万上下文与"推理深度分档"重新定义旗舰；Claude Fable 5.1 把缓存读价砍至 $0.25 拉开价格战的第二战场；Kimi K3（2.8T 总参/104B 激活、AA 指数 57）与 DeepSeek V4 Pro（1.6T/49B 激活、MIT 协议）把开源前沿推至闭源 90 天身位内。资本侧：OpenAI 累计算力承诺超 $7000亿（10GW 目标提前 3 年达成，Altman 指向 2033 年 250GW≈$10万亿）；Anthropic ARR 一年 7 倍至 $650亿、拟以 $2万亿+ 估值于 2026 年 10 月 IPO。硬件侧：Rubin R100 进入量产爬坡（288GB HBM4/22TB/s/NVLink 6）；AMD Helios 机柜（72×MI455X，OpenAI 6GW+认股权证绑定）开启"第二供应商"时代；博通 FY26 AI 收入 $580亿（+186%），Anthropic+OpenAI 取代 Google 成为最大 ASIC 客户——定制芯片对 GPU 的结构性分流正式开始。
