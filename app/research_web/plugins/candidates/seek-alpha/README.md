# 小创数据候选包 0.1.0

此包由 RWB 定义，仅包含供应商公开端点和候选说明；不是供应商官方发布包或 Registry 登记证明。

导入现有插件界面后，MCP 组件保持 `unsupported/native_registry_selection_required`。
包审批不代表 MCP 安装、schema 审批、当前会话授权、付费授权或内容质量准入。

固定端点为 `https://seek-alpha.cn/mcp/rpc`。包不含账号、Bearer、环境值、执行脚本或工具 schema。
必须先取得供应商真实 Registry ID、server name、固定版本和指向此端点的 remote index，
经既有 Registry 安装预览及确认后才能绑定受管组件。

之后仅在当前账户的凭据库录入个人 Bearer，经独立握手、管理员实际 schema 审批与会话授权后评估。
不得把本包文件名、版本 0.1.0 或 `seek-alpha` 名称当成远端服务器的 Registry 身份或协议版本。

首轮评估：600519.SH、300750.SZ、688981.SH；产业链、机构调研、一致预期、预测调整、
预告超预期、风险标签，共 18 个固定调用，每次上限 3 子弹、总上限 54 子弹。
清单取数截止日期由用户选择，产业链只有当前关系、没有历史可知资格。
先预览每项参数与真实 schema，再单独确认清单/预算；每次启动只执行一项。
未知受理不重发、不释放额度，取消不推定退款。所有结果先作为待核验线索。
